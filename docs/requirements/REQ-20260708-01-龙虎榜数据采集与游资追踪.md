# 需求文档：龙虎榜数据采集与游资追踪

## 1. 概述

- **项目名称**：龙虎榜数据采集与游资追踪模块
- **需求来源**：主人要求采集龙虎榜上榜数据，追踪章盟主操作
- **目标**：每日收盘后拉取沪深两市龙虎榜数据，存储到项目数据库，自动标注章盟主相关买入/卖出记录

## 2. 功能需求

### 2.1 龙虎榜数据采集

- 数据范围：沪深两市每日龙虎榜上榜明细（含上榜股票、买卖前五席位、成交金额等）
- 数据源：AKShare `stock_lhb_detail_em()` 接口（东方财富龙虎榜）
- 采集频率：每日收盘后（与现有 `daily_fetch.py` 同步，建议在16:00-16:30间）
- 采集内容：
  - 上榜日期
  - 股票代码、名称
  - 上榜原因（偏离值/换手率/振幅等）
  - 买方前五席位（营业部名称、买入金额、买入占比）
  - 卖方前五席位（营业部名称、卖出金额、卖出占比）
  - 买卖总金额、净买入金额

### 2.2 游资追踪（章盟主）

- **章盟主已知专用营业部**（主人提供）：
  1. 国泰海通证券上海浦东新区海阳西路
  2. 中信证券杭州延安路
  3. 国泰海通证券宁波广福街
  4. 国泰海通证券上海徐汇区建国西路
  5. 中信证券杭州富春路
- 功能：在上榜数据中自动匹配以上营业部，生成追踪记录
- 记录内容：股票、方向（买入/卖出/净买卖）、金额、日期

### 2.3 数据存储

- 建表：`lhb_detail`（龙虎榜明细）、`lhb_tracker`（游资追踪结果）
- 使用现有 DAO 层（MySQL）

## 3. 数据模型

### 3.1 lhb_detail 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT AUTO_INCREMENT | 主键 |
| trade_date | DATE | 交易日期 |
| stock_code | VARCHAR(10) | 股票代码 |
| stock_name | VARCHAR(20) | 股票名称 |
| reason | TEXT | 上榜原因 |
| buy_amount | DECIMAL(20,2) | 买入总额 |
| sell_amount | DECIMAL(20,2) | 卖出总额 |
| net_amount | DECIMAL(20,2) | 净买入额 |
| buy_detail | JSON | 买方前五详情 |
| sell_detail | JSON | 卖方前五详情 |
| created_at | TIMESTAMP | 创建时间 |
| UNIQUE KEY | (trade_date, stock_code) | |

### 3.2 lhb_tracker 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT AUTO_INCREMENT | 主键 |
| trade_date | DATE | 交易日期 |
| stock_code | VARCHAR(10) | 股票代码 |
| stock_name | VARCHAR(20) | 股票名称 |
| trader_name | VARCHAR(30) | 游资名称（如"章盟主"） |
| branch | VARCHAR(100) | 营业部名称 |
| direction | VARCHAR(10) | 方向：buy/sell |
| amount | DECIMAL(20,2) | 买卖金额 |
| lhb_reason | TEXT | 上榜原因 |
| created_at | TIMESTAMP | 创建时间 |
| INDEX | (trade_date, trader_name) | |

## 4. 采集方式

- 每日调一次 AKShare `stock_lhb_detail_em(date)`，遍历返回的所有股票记录
- 解析买卖前五营业部，存入 `lhb_detail`
- 同时检查营业部名称是否匹配章盟主名单，匹配则写入 `lhb_tracker`

## 5. 不包含

- 当日盘后追踪结果推送（后续可加，初期仅存储）
- Web 端展示（可通过查询数据库查看）
- 多个游资同步追踪（初期仅章盟主，后续可扩展）
