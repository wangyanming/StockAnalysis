# 需求文档：新版选股系统（以市场主线为锚）

## 概述

重新设计收盘选股系统，从"通用评分+分组过滤"模式升级为"主线锚定+资金辨识度+量价结构"三位一体的短线选股方案。核心变化：不再对全市场所有活跃股打同一个模版分，而是先锁定资金主攻方向，再在主线上找最有辨识度的标的。

主要版本：V2（现版）→ V3（新版）

## 背景

### 现有系统

现有 `daily_pick_v2.py` 构建候选池的逻辑：
```
全市场金额>5亿 + 市值>=100亿 + 近3月有涨停 → 候选池(≈300只)
    ├── 涨停回踩组：近5天首板涨停 → 缩量回调不破起涨点 → 前5
    └── 区间潜伏组：非涨停 → 趋势评分达标 → 60日低分位 → 前5
```

评分模型（`scorer.py` v5.5）6个维度：
- 筹码结构(25分)：位置+量价+沉淀
- 资金接力(25分)：换手+封板+分时
- 板块环境(20分)：涨停家数+连板+题材
- 趋势位置(20分)：均线+MA20距离+节奏
- 大盘安全(10分)：大盘状态
- 位置评估(15分bonus)：20日区间低位加分

### 核心矛盾

日线复盘过去30个交易日，选股胜率远低于目标70%，根因分析：

| 问题 | 表现 | 根因 |
|------|------|------|
| **策略偏防守** | "涨停回踩+区间潜伏"本质是两个回调策略 | 弱势行情中回调≠洗盘，很多是"接飞刀"（跌下去不再回来） |
| **评分维度与赚钱能力不相关** | 高分票（>80分）次日表现并不优于中分票（60-70分） | 筹码结构/均线排列/位置评估等维度是"防守质量"打分，不是"攻击力"打分 |
| **精选过滤太严** | 被过滤掉的票常常次日涨幅大于入选的 | 区间潜伏组过滤链太长（趋势分>=10→位置分>=3→总市值>=50亿→非科创/创业→60日位置<50%→波幅>20%→阳线≥3→5日涨跌幅2-15%→量能0.8-2.5倍→不破MA5），敏感度过高 |
| **不在主线上** | 选出的票多数不是今年主攻方向（AI/算力/低空/机器人/新能出海） | 评分系统没有对"主线板块"做强制过滤或加权激励 |

### 数据验证（2026-05-13 ~ 2026-06-10，约20个交易日）

| 指标 | 数据 |
|------|------|
| 入选票日均跑赢大盘 | +0.12%（差） |
| 入选票次日上涨概率 | 约42% |
| 入选票3日上涨概率 | 约48% |
| 大盘当日>0.5%时入选胜率 | 约51% |
| 大盘当日<-0.5%时入选胜率 | 约28% |
| 属于AI/算力/低空/机器人板块的入选占比 | <15% |
| 属于传统行业（化工/钢铁/基建）的入选占比 | >35% |

结论：选股系统在大盘好时勉强跑平，大盘差时明显跑输；选票集中在非主线传统行业。

## 用户需求

1. **以主线为锚**：选股必须先锁定当前市场主攻方向（板块/概念），只在主线上选
2. **人气辨识度优先**：谁在涨停榜上？谁在板块前排？谁有连板或反包气质？——这些比筹码结构重要
3. **量价结构判断**：不是简单"放量就好/缩量就不好"，而是判断量大是否一致性太强（容易分化），量小是否流动性枯竭
4. **策略分层**：不同行情用不同策略，不做"一刀切"的通用评分：
   - 主线上涨阶段：做趋势加速票
   - 主线回调阶段：做龙头缩量回踩
   - 无主线轮动阶段：做资金抱团辨识度票
5. **精选规则从简**：去掉多层过滤，精选标准改为"够得上策略条件 + 无重大风险"

## 功能列表

### F1 市场主线识别（新增）
- **输入**：当日涨停行业分布、板块涨幅榜、连板梯队
- **输出**：当前主线板块TOP3（含板块名、涨停数、龙头标）
- **规则**：
  - 按"板块涨停数*0.4 + 板块涨幅*0.3 + 最高连板数*0.3"综合评分
  - 评分≥60分且涨停数≥3只 → 称为"主线板块"
  - 评分≥80分且涨停数≥8只 → 称为"强主线板块"
  - 无板块同时满足以上条件 → "无主线轮动日"

### F2 策略中枢（新增）
根据主线识别结果自动切换策略：

| 模式 | 触发条件 | 策略 | 示例 |
|------|----------|------|------|
| **强主线趋势** | 强主线板块≥1个（涨停≥8只） | 主线上找趋势加速/核心辨识度票 | AI爆发日做算力趋势核心 |
| **主线回调低吸** | 主线板块存在但龙头回调 | 主线龙头缩量回踩5/10日线 | 主线调整2-3天后的龙头回踩 |
| **无主线轮动** | 无强主线/主线评分<60 | 资金抱团辨识度（连板龙头/反包/n字板/近期妖股） | 缩量震荡日找连板首分岐 |

### F3 人气辨识度评分（替代原筹码结构维度，25分）
- **涨停辨识度(12分)**：近5日涨停次数、是否板块龙头（最早封板/最高连板）
- **资金辨识度(8分)**：近5日日均成交额在板块内排名、换手率是否健康
- **股性活跃度(5分)**：近10日振幅均值、换手率标准差（有波动才有人做）

### F4 主线属性评分（替代原板块环境维度，25分）
- **主线锚定(15分)**：个股所在板块/概念是否属于当前主线TOP3
- **板块地位(10分)**：在主线板块中的位置（龙头+10，前排跟风+6，后排+2，非主线0）
- 不再用"6个行业有涨停+3分"这类模糊加分

### F5 量价结构评分（替代原资金接力+趋势位置部分，30分）
- **分歧一致判断(12分)**：
  - 放量涨停 = 分歧转一致 → 好
  - 缩量涨停 = 一致性太强 → 明天容易分化
  - 放量不涨 = 出货/压力大 → 差
  - 缩量回踩 = 惜售/洗盘 → 好（在主线回调场景）
- **趋势强度(10分)**：
  - 多头排列且价格在MA5之上运行 → 趋势维持
  - 回调到支撑位缩量企稳 → 回调到位
- **量能健康度(8分)**：
  - 量比0.8-1.5 → 正常，1.5-3 → 活跃，>3 → 过热，<0.5 → 冷清

### F6 大盘环境（10分，保留v5体系，仅优化阈值）
- 不做（跌>1.5%）→ 0分
- 谨慎（跌0.5-1.5%）→ 3分
- 正常（±0.5%）→ 7分
- 做多（涨>0.5%）→ 10分
- 加分：主线板块≥2个 → +3分

### F7 流动性过滤（改名"风险过滤"，10分）
- 原来分散在多个维度的风险判断统一收敛到此维度：
  - ST/退市/停牌 → 一票否决
  - 市值<30亿 → -5分
  - 近3日累计跌>12%且无支撑 → -5分
  - 近5日有收到问询函/监管函 → -3分
  - 所属行业板块当日跌幅>3% → -5分

### F8 精选(is_pick)规则
- 简化：每个策略策略取TOP5
- 取消复杂的多层过滤链
- 精选标准仅为：
  1. 满足对应策略条件的候选（硬条件通过）
  2. 总评分排序前5
  3. 无一票否决项（ST/退市/停牌）

### F9 收盘复核（保留ReAct复盘体系）
- 每日复盘时输出本次选股评分中各个维度的实际贡献度
- 定期（每5个交易日）统计各维度的预测准确率
- 维度贡献度低于5%的自动标记"待优化"

## 非功能需求
1. 数据源不新增外部API，全量数据从现有DB表读取（stock_daily, daily_limit_up, sector_performance）
2. 与现有`daily_pick_v2.py`并行运行，新系统命名为`daily_pick_v3.py`
3. 选股结果落库到`daily_picks`表（与v2共用，以trade_date+source字段区分）
4. `close_task.py`改为调用v3输出
5. `bash tests/check_engineering.sh`通过
