# 需求文档：商业基本面分析 Agent (REQ-20260617-01)

## 1. 背景
目前选股系统聚焦于技术面（量价、趋势、资金面），缺乏对公司基本面的系统性分析。实战中需要了解候选股的：
- 主营业务是否清晰、有成长性
- 在产业链中的位置和议价能力
- 财务健康状况（营收、利润、现金流、负债）
- 股东结构（机构持仓、大股东增减持）

人工逐一查这些太耗时，需要一个自动化基本面分析工具。

## 2. 目标
开发一个「基本面分析 Agent」，输入股票代码，自动输出结构化基本面报告。

## 3. 报告内容要求

### 3.1 公司概览
- 公司全称、上市板块、市值区间
- 主营业务描述（具体产品/服务，收入占比）

### 3.2 产业链定位
- 上下游分别是什么行业/公司
- 在产业链中的话语权（毛利率、应收账款周转等体现）

### 3.3 财务分析（近3-4年+最近季报）
- 营收和增长率
- 归母净利润和增长率
- 毛利率、净利率趋势
- ROE
- 资产负债率
- 经营现金流/净利润比（含金量）
- 应收账款/营收比

### 3.4 估值对比
- PE（静态/动态）、PB
- 所处行业的中位数对比
- 历史PE分位

### 3.5 股东分析
- 前十大流通股东
- 机构持仓变化（基金增减持）
- 高管/大股东增减持情况

### 3.6 投资评级
- 综合打分（1-5星）：财务健康度、成长性、估值合理性、产业链地位
- 看法说明（一句话结论）

## 4. 数据源策略

### 首选（免费可用的公开接口）
| 数据 | 来源 | 优先级 |
|------|------|--------|
| 公司基本信息、主营业务 | AKShare（`stock_info_company`） | 1 |
| 财务三表 | AKShare（利润表/资产负债表/现金流量表） | 1 |
| 财务指标（ROE/毛利率等） | AKShare（财务指标） | 1 |
| 估值数据（PE/PB） | 新浪/腾讯实时行情 + 日线推算 | 2 |
| 股东信息 | AKShare（`stock_fund_holder`） | 2 |
| 行业分类/产业链 | 同花顺板块数据（已有） | 3 |

### 备选
- 东财HTTP接口（非官方）
- 手动提示用户参考同花顺/东方财富F10

## 5. 输出格式
统一输出为 Markdown 结构化报告，分 6 段，包含**数值+解读**。

## 6. 验收标准
1. 对任意A股代码，能输出完整的6段报告
2. 财务数据至少包含最近2年+最近季报
3. 每个数据点附带1-2句解读说明
4. 最终有星级评分和一句话看法
5. 无关键字段缺失时不能静默失败
