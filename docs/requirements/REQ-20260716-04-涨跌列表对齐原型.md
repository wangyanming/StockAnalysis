# 需求文档：涨停/跌停列表对齐产品原型

**版本:** v1.0
**日期:** 2026-07-16
**状态:** 草稿

## 1. 背景

当前涨停/跌停列表仅展示 5 列，与产品原型（`web_prototype.html`）相比缺少关键指标列如换手率、封板时间、开板次数、封板资金、行业等。
