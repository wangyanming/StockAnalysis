# 需求文档 — StockAnalysis Web 前端

**版本:** v2.0
**日期:** 2026-07-15
**状态:** 草稿

---

## 1. 产品定位

StockAnalysis Web 前端是股票分析系统的可视化界面，提供大盘概览、涨跌复盘、选股追踪三大核心功能。数据来源于后端 HTTP API（web_server.py），纯前端渲染，零外部依赖。

---

## 2. 功能范围

### 2.1 功能模块

| 模块 | 子功能 | 说明 |
|------|--------|------|
| **大盘概览** | 指数看板 | 展示上证/深证/沪深300/创业板/科创50的最新价和涨跌幅（指标卡片横排，grid 5列等宽） |
| | 涨跌家数 | 当日上涨/下跌/平盘家数及总数 |
| | 成交额对比 | 当日成交额（在前）+ 较昨日变动（在后） |
| | 涨幅TOP10板块 | 涨幅居前10个板块（板块名称、涨幅、成交额、净流入、上涨家数、下跌家数） |
| | 跌幅TOP10板块 | 跌幅居前10个板块（字段同上） |
| **涨跌复盘** | 涨停列表 | 按日期查询涨停股票，支持分页/排序 |
| | 跌停列表 | 按日期查询跌停股票，支持分页/排序 |
| | 行业分布 | 按日期统计涨停行业分布（名称、涨停数、代表个股） |
| | 日期选择 | 选择交易日 + 查询按钮 |
| **选股追踪** | 维度筛选 | 全部/涨停接力/区间潜伏 |
| | 日期筛选 | 选择日期 |
| | 候选列表 | 入选股票 + 后续5日涨跌幅追踪 |

### 2.2 不做

- 个股详情页（接口已有，UI 待实现）
- 指数 K 线图（接口已有，UI 待实现）
- 板块表现独立页面（合并到大盘概览TOP10）
- 涨停追踪独立页面
- 响应式/移动端适配
- 主题切换/国际化

## 3. 用户交互流程

### 3.1 页面布局
- 左侧深色菜单（宽约200px）：大盘概览 / 涨跌复盘 / 选股追踪
- 右侧内容区：根据菜单项切换显示

### 3.2 交互点

| 交互 | 触发 | 数据来源 |
|------|------|---------|
| 页面加载 | 打开 `http://localhost:8899` | `/api/market-overview` + `/api/market-summary` + `/api/sectors` |
| 菜单切换 | 点击左侧菜单项 | 切换内容区，涨跌复盘/选股追踪首次打开时加载数据 |
| 日期选择 | 下拉选择 + 点击查询 | `/api/limit-up?date=` + `/api/limit-up/industry?date=` |
| 分页 | 点击页码或修改每页条数 | 前端本地过滤 |
| 排序 | 点击表头 | 前端本地排序 |
| 手动刷新 | 右上角刷新按钮 | 重新请求所有当前模块数据 |
| 自动刷新 | 每60秒 | 大盘概览数据自动刷新 |

## 4. 数据依赖

| API | 模块 | 说明 |
|-----|------|------|
| `/api/market-overview` | 大盘概览 | 指数行情、热门股票 |
| `/api/market-summary` | 大盘概览 | 涨跌家数、成交额及对比 |
| `/api/sectors` | 大盘概览 | 板块排行（涨幅TOP10/跌幅TOP10） |
| `/api/limit-up?date=` | 涨跌复盘 | 涨停列表 |
| `/api/limit-up/industry?date=` | 涨跌复盘 | 涨停行业分布 |
| `/api/limit-up/dates` | 涨跌复盘 | 可选日期列表 |
| *(待开发)* 选股历史API | 选股追踪 | 每日选股列表+后续追踪 |

---

## 5. 非功能需求

| 维度 | 要求 |
|------|------|
| 加载时间 | 页面总耗时 < 3s |
| 容错 | API失败显示错误信息，不白屏不卡死 |
| 刷新 | 大盘概览每60秒自动刷新 |
| 兼容 | Chrome/Firefox/Safari/Edge 最新两版本 |
| 依赖 | 零外部CDN，内联HTML/CSS/JS |

## 5a. UI 规范

| 元素 | 规范 |
|------|------|
| 布局 | 左侧深色菜单（~200px）+ 右侧内容区 |
| 指数看板 | grid 5列等宽卡片，无留白 |
| 板块排行 | 涨幅/跌幅上下两独立表格（纵向排版），表头：板块名称、涨幅/跌幅、成交额、净流入、上涨家数、下跌家数 |
| 涨跌复盘 | 涨停/跌停两表格，各自独立分页（可选10/20/50/100），表头可点击排序 |
| 选股追踪 | 维度筛选（全部/涨停接力/区间潜伏）+ 日期筛选 |
