# REQ-20260716-02-统一展示日期规则

## 1. 背景

当前 StockAnalysis 项目的不同接口在"自动选择展示哪天的数据"时逻辑不统一：
- `market-overview` 直接调新浪实时
- `market-summary` 直接查当天日期
- `sectors` 直接取 `MAX(record_date)`
- `limit-up` / `limit-down` / `limit-up/industry` 用 `datetime.now().strftime("%Y%m%d")`

各处的"今天/昨天"判断不一致，且没有考虑周末/节假日无数据的情况。

## 2. 需求

在 `utils/` 下新增一个通用工具函数 `get_display_date()`，统一所有接口的"自动选日期"行为。

## 3. 规则

```
当前时间 ≥ 17:00 → 展示 T 日（今天）
当前时间 < 17:00 → 展示 T-1 日（昨天）

如果目标日期不是交易日（查询 stock_daily 表判断），
则逐日往前找，直到找到最近有数据的交易日。
```

## 4. 函数签名

```python
def get_display_date() -> str:
    """返回当前应展示的日期，YYYYMMDD 格式"""
    ...
```

放置位置：`utils/date_utils.py`（新建文件），或放入现有工具模块。

## 5. 影响范围

需改动的接口（共 6 个）：

| 接口 | 当前行为 | 改后行为 |
|------|---------|---------|
| `api_market_overview` | 调新浪实时 | 改为从 `index_quotes` 表按 `get_display_date()` 查 |
| `api_market_summary` | 查当天 `sector_performance` | 按 `get_display_date()` 查 |
| `api_sectors` | `MAX(record_date)` 取最新 | 按 `get_display_date()` 查 |
| `api_limit_up` | 默认 `now.strftime` | 默认走 `get_display_date()` |
| `api_limit_down` | 同上 | 同上 |
| `api_limit_up_industry` | 同上 | 同上 |

## 6. 验证标准

1. 周一 09:00 → 返回上周五日期（跳过周末）
2. 周三 17:00 → 返回周三日期
3. 周四 15:00 → 返回周三日期（周四数据未采集）
4. 周五 18:00 → 返回周五日期
5. 春节假期后周一 → 跳过整个假期，返回假期前最后交易日
