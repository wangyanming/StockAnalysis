# 需求文档：低吸抄底选股引擎 v3

## 概述
基于数据回测结论，重构选股引擎：从现有的综合评分体系（涨停接力+区间潜伏）改为"大跌抄底+缩量"核心策略，辅以放量反转备用策略。

## 回测结论（不可更改）

### 核心策略A：大跌抄底+缩量
- 条件：今日跌幅≥5% + MA20乖离率≤-8% + 量比<1.5
- 胜率：65.9%（N=3,478），平均收益+0.86%
- 持仓：T+1开盘买入，T+2开盘卖出

### 备用策略D：放量反转
- 条件：今日阳线(close>open) + 涨幅1-9.5% + 昨日跌≥2% + devMA20≤-6% + 量比>1.5
- 胜率：60.6%（N=343）

### 无效策略（放弃）
- 连跌缩量见底（42.1%）
- 涨停次日低开（46.1%）
- 涨停追高（48%）
- 加价格/市值过滤反而降胜率

## 影响文件
1. `core/analyzer/daily_pick_v3.py` — 新选股引擎（新增，不改v2）
2. `core/analyzer/close_task.py` — 第5段明日候选改为v3输出格式
3. MEMORY.md / PROJECT_STATE.md — 文档更新
