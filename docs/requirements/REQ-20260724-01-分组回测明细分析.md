# 分组回测明细分析需求

**版本:** v1.0
**日期:** 2026-07-24
**状态:** 待评审

## 1. 背景

已完成基线回测（`bt_baseline`，5/13~7/23，49笔交易）。观察到不同评分分组的胜率和收益差异明显，需要进一步细化分组粒度，对每个评分区间的所有候选股逐一回测，以明确不同区间的表现特征和原因。

## 2. 需求范围

### 2.1 做（Scope In）

1. 新建独立回测脚本，对 2026-05-13 ~ 2026-07-21 区间内的每日选股候选进行分组回测
2. 候选股来源：`daily_picks` 表的选股结果
3. 分组规则：
   - **A组**：`total_score < 60`，取评分前5名候选
   - **B组**：`60 <= total_score < 65`，取全部候选
   - **C组**：`65 <= total_score < 70`，取全部候选
   - **D组**：`total_score >= 70`，取全部候选
4. 每组独立进行 T+1 开盘买入、T+2 开盘卖出的交易模拟
5. 每组输出完整结果（交易明细 + 汇总统计）

### 2.2 不做（Scope Out）

1. 不涉及策略A/B策略组合优化
2. 不修改现有 `backtest_controller.py` 或 `backtest_picks` 表
3. 不涉及<60分以外的候选股数量限制
4. 不包含连亏暂停/止损等风控逻辑

### 2.3 输入/触发条件

- 输入：`daily_picks` 表中 2026-05-13 ~ 2026-07-21 的选股记录
- 数据依赖：`stock_daily` 表（K线数据，含open/close/volume）
- 触发：手动运行 Python 脚本

### 2.4 输出/结果形态

1. 四组独立结果写入带分组标记的表中或分表
2. 每组输出：
   - 交易明细（选股日、代码、名称、评分、买入日、买入价、卖出日、卖出价、收益率）
   - 汇总统计（交易次数、胜率、总收益、平均收益、最大盈利、最大亏损）
3. 输出到 CSV 文件或终端表格
4. 生成分组对比报告

## 3. 验收标准

1. 每组交易明细可逐笔验证（收益率 = (卖出价 - 买入价) / 买入价）
2. A组最多5笔/天，BCD组取全部
3. 日期区间严格 2026-05-13 ~ 2026-07-21
4. 跳过 2026-06-19 假期
5. T+1/T+2 开盘停牌或一字板缩量的处理符合基线逻辑
6. 四组汇总数据可对比分析
