## 1. 背景

`web_server.py` 当前注册了两个前端页面入口：

1. **`GET /`（含 `/index.html`）** → `serve_html()` → `_build_html()` — **废弃，待删除**
2. **`GET /web_app.html`** → `serve_web_app()` → `docs/design/web_app.html` — **当前在用的正式前端**

废弃入口 `/` 从项目初始就存在，生成一个全内嵌式的 HTML+JS 页面（行 485–901，约 417 行）。该入口已被 `/web_app.html` 取代约 7 天（自 2026-07-16 的 web_app.html 上线后）。

## 2. 废弃代码分析

### 2.1 代码位置

| 方法 | 行号 | 行数 |
|------|------|------|
| `serve_html()` | 98–103 | ~6 行 |
| `_build_html()` | 485–901 | ~417 行 |

### 2.2 方法调用链

```
┌─ do_GET() ──┐
│ path == "/"  │──→ serve_html() ──→ _build_html() → return str(HTML)
│ or index.html│
└──────────────┘
    ↓ 路由匹配
if path == "/" or path == "/index.html":
    self.serve_html()
```

### 2.3 引用扫描

对整个项目（含 .py / .html / .sh / .md）执行了 `grep -rn` 搜索：

- **`serve_html`**：仅在 `web_server.py` 内部定义和调用（行 63、98），**无外部引用**
- **`_build_html`**：仅在 `web_server.py` 定义和调用（行 100、485），**无外部引用**
- **外部文档提及**：仅有 `docs/design/DES-20260716-01-Web前端原型技术方案.md` 第 241 行提到"用户直接访问 `http://localhost:8899/` 即可"——这是历史方案文档，删除代码后此描述不再准确，但文档作为历史记录可保留不做修改

**结论：`serve_html()` 和 `_build_html()` 是私有方法，无外部依赖，删除安全。**

### 2.4 影响分析

| 检查项 | 结果 |
|--------|------|
| 其他 API 路由是否受影响 | 否 — `do_GET()` 是链式 elif，删除一条分支不影响其他分支 |
| 外部模块导入 | 无 — `_build_html()` 内不调用业务逻辑外的模块 |
| 缓存系统 `_cache` | 无依赖 — `_build_html()` 内部自行 fetch API，不写缓存 |
| 客户端访问 | 原 `/` 页面用户需要跳转到 `/web_app.html` |
| 单元测试 | 项目无 `/` 的测试用例 |

## 3. 删除方案

### 3.1 要删除的代码

**A. 路由分支（`do_GET()` 第 62–63 行）**

```python
# 删除这两行：
if path == "/" or path == "/index.html":
    self.serve_html()
```

**B. 替换为重定向**

```python
# 改为：
if path == "/" or path == "/index.html":
    self.redirect("/web_app.html")
```

**C. 新增 `redirect()` 辅助方法**（放在 `send_json` 附近）

```python
def redirect(self, location: str):
    self.send_response(302)
    self.send_header("Location", location)
    self.end_headers()
```

**D. 删除 `serve_html()`（行 98–103）**

整个方法删除。

**E. 删除 `_build_html()`（行 485–901）**

整个方法删除。

### 3.2 保留逻辑

- 所有 API 路由（`/api/*`） 全部保持不动
- `serve_web_app()` 方法保持不动
- `serve_static()` 方法保持不动
- `web_app.html` 文件保持不动
- `start_server()` / `start_daemon()` / `_run_daemon()` 保持不动

## 6. 测试验收标准

1. 访问 `http://localhost:8899/` → **302 跳转**到 `http://localhost:8899/web_app.html`（浏览器自动跟随）
2. 访问 `http://localhost:8899/web_app.html` → **200 OK**，正常渲染前端页面
3. 访问 `http://localhost:8899/api/market-overview` → **200 OK**，返回 JSON
4. 所有 `/api/*` 端点返回正常
5. 已有用户书签 `http://localhost:8899/` 仍能到达前端页面（通过 302 跳转）

## 7. 实施建议

- 建议在非交易时段（如 15:00 后）部署
- 发布后观察 `403/404` 日志，确认无异常
- 可考虑在 LOG 中标注一次 `[INFO] / redirected to /web_app.html`，便于后续统计废弃入口的残余访问量

## 附录：废弃代码内容摘录

删除的 `_build_html()` 包含了以下功能（仅供备忘，不保留）：

- **CSS 样式**：约 40 行内联 CSS（基础布局、颜色、卡片样式）
- **HTML 结构**：约 50 行静态 HTML（头部、Tab 导航、各 Tab 容器）
- **JavaScript 逻辑**：
  - `refresh()` — 手动刷新
  - `loadData()` — 获取市场概况、市场总结、板块排名
  - `loadZtData()` — 加载涨停板数据 + 行业分布

  - `showTab()` — Tab 切换
  - 30 秒自动刷新 `setInterval(loadData, 60000)`

以上所有功能均在 `web_app.html` 中已有对应实现（且更完整）。
