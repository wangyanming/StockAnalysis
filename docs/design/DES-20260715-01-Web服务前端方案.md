# 方案设计 — StockAnalysis Web 前端

**版本:** v2.1
**日期:** 2026-07-16

---

## 1. 架构概览

```
┌─────────────────────────────────────┐
│         浏览器 (前端)                 │
│  HTML + CSS + JS (内联单页)          │
│                                     │
│  左侧菜单 → 右侧内容区               │
│  fetch() → API → 渲染 HTML           │
│  setInterval 60s 自动刷新            │
└──────────────┬──────────────────────┘
               │ HTTP (localhost:8899)
┌──────────────▼──────────────────────┐
│     web_server.py (ThreadingHTTPServer)│
│                                      │
│  /api/market-overview  (cached 30s)  │
│  /api/market-summary  (cached 30s)   │
│  /api/sectors          (cached 60s)  │
│  /api/limit-up?date=   (cached 60s)  │
│  /api/limit-up/industry?date=        │
│  /api/limit-up/dates   (cached 300s) │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│     后端数据层                        │
│  StockDataFetcher                    │
│  LimitUpAnalyzer                     │
│  MySQL (sector_performance/stock等)  │
└─────────────────────────────────────┘
```

**核心设计思想：** 纯前端 SPA（但非框架，是原生JS），后端单文件 HTTP Server。所有数据通过 fetch() 从后端 API 获取，前端负责渲染和交互。

## 3. 模块设计

### 3.1 大盘概览

| 卡片 | 内容 | 数据源 |
|------|------|--------|
| 指数看板 | 5指数表格（名称、最新价、涨跌幅） | `/api/market-overview` |
| 市场总结 | 涨跌家数 + 成交额及对比 | `/api/market-summary` |
| 涨幅TOP10板块 | 板块名称、涨幅、成交额 | `/api/sectors` → 排序取前10 |
| 跌幅TOP10板块 | 板块名称、跌幅、成交额 | `/api/sectors` → 排序取后10 |

### 3.2 涨跌复盘

| 组件 | 设计 |
|------|------|
| 日期选择器 | 下拉框（来自`/api/limit-up/dates`）+ 查询按钮 |
| 涨停列表 | 10列表格，支持分页+排序 |
| 跌停列表 | 8列表格，支持分页+排序 |
| 行业分布 | 3列表格（行业、涨停数、代表个股） |

#### 分页控件
```
◀ 1 2 3 ... 8 ▶   每页: [10 ▼]
```
- 页码按钮：上一页/下一页 + 数字页码
- 每页条数下拉：10/20/50/100

#### 排序逻辑
- 点击表头切换排序方向（asc/desc/无）
- 排序字段：涨幅、连板数、封板资金、换手率等
- 纯前端排序，不请求后端

### 3.3 选股追踪

| 组件 | 设计 |
|------|------|
| 维度筛选 | 下拉框：全部 / 涨停接力 / 区间潜伏 |
| 日期筛选 | 日期选择器 |
| 候选列表 | 表格（代码、名称、入选日期、维度、后续5日涨跌幅） |

注意：选股追踪当前无后端 API，原型中使用模拟数据占位。

## 4. API 接口设计

| 接口 | 方法 | 参数 | 返回 | 缓存TTL |
|------|------|------|------|---------|
| `/api/market-overview` | GET | 无 | indexes + popular_stocks | 30s |
| `/api/market-summary` | GET | 无 | 涨跌家数 + 成交额对比 | 30s |
| `/api/sectors` | GET | 无 | 板块排行数据 | 60s |
| `/api/limit-up` | GET | ?date= | 涨停列表 | 60s |
| `/api/limit-up/industry` | GET | ?date= | 行业分布 | 60s |
| `/api/limit-up/refresh` | GET | 无 | 触发涨停数据采集 | 无 |
| `/api/limit-up/dates` | GET | 无 | 可选日期列表 | 300s |
| `/api/index` | GET | ?code= | 指数详情+K线 | 30s |
| `/api/stock` | GET | ?secid= | 个股行情 | 30s |
| `/api/history` | GET | - | 历史数据 | 60s |

---

## 5. 缓存策略

- **后端内存缓存**：`_cached_call()` 实现，TTL 30-300s，线程安全
- **前端无缓存**：每次切换菜单或定时刷新重新 fetch
