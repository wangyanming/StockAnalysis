**版本:** v1.0
**日期:** 2026-05-27
**关联需求:** REQ-20260527-02-ReAct三闭环集成
**状态:** 已定稿

---

## 1. 总体方案

在 close_task.py 中调 pick_react.run_react_analysis() 替代 _build_react_data()，输出直接拼为文本段落插入复盘消息第4段。模版层（close_report_tpl.py）不改。

## 2. 模块划分

### 2.1 修改文件

| 文件 | 类型 | 说明 |
|------|------|------|
| `core/analyzer/close_task.py` | 修改 | 第795行将 `_build_react_data()` 调用改为 `pick_react.run_react_analysis()`，并将返回文本拼到 data 中作为新字段 |

### 2.2 不修改的文件

| 文件 | 原因 |
|------|------|
| `core/reporter/close_report_tpl.py` | 纯模版层，`data['react_report_text']` 文本直接追加，不涉及 Template 变动 |
| `core/analyzer/pick_react.py` | 已有完整的 Observe→Thought→Act，输出已经是格式化文本，不需要额外调整 |
| 不涉及数据库表结构 | observe_log 已存在 |

## 3. 数据流

```
close_task.py _run_analysis()
  └─ _load_yesterday_picks(trade_date)        ← 不变，继续加载昨日候选
  └─ _build_react_data() 改为:
       pick_react.run_react_analysis(check_date)  ← 返回多行文本
                                                    包含 Observe 统计
                                                    + Thought 归因
                                                    + Act 建议
  └─ data['react_report_text'] = 返回文本       ← 新增字段
  └─ render_report(data)                         ← 模版只追加该文本
```

## 4. 数据存储设计

### 4.1 无新增表

现有 `observe_log` 表已由 pick_react.update_feedback() 管理足够。

## 5. 接口设计

无新增接口。只改一处调用关系：

```python
# 改前
react_data = _build_react_data(trade_date, yesterday_picks)  # 返回 dict

# 改后
from core.analyzer.pick_react import run_react_analysis
react_text = run_react_analysis(check_date=trade_date)  # 返回 str
```

## 6. 配置项

无

## 7. 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| pick_react 模块 import 失败 | try/except 包裹，回退到 _build_react_data() 简版 |
| run_react_analysis 异常 | try/except 包裹，回退并打日志 |
| run_react_analysis 返回空文本 | 不追加 React 段落 |
