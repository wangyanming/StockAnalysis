# 分组回测明细分析方案

**版本:** v1.0
**日期:** 2026-07-24
**状态:** 待评审

## 1. 需求概述

对 v5 评分体系的每日候选股按评分分组进行独立回测，A组(60分)取Top5、BCD组取全部，输出每组交易明细及对比报告。

## 2. 方案设计

### 2.1 数据流

```
daily_picks(选股结果) 
    → 按评分分组(A/B/C/D)
    → 按组逐日模拟T+1开盘买入、T+2开盘卖出
    → 写入 backtest_group_results 表
    → 输出分组对比报告
```

### 2.2 代码结构

新增文件：`backtest/group_backtest.py`
独立运行脚本，不修改现有代码。

### 2.3 核心逻辑

```
for each trade_date in [20260513..20260721]:
    picks = query daily_picks where trade_date=trade_date
    
    for each group in [A, B, C, D]:
        candidates = filter picks by group rules
        
        for each candidate:
            # T+1 开盘买入
            find next_trade_date after trade_date
            buy_price = stock_daily.open at next_trade_date
            
            # T+2 开盘卖出  
            find next_next_trade_date after next_trade_date
            sell_price = stock_daily.open at next_next_trade_date
            
            # 跳过检查
            if volume=0 or (change_pct>=9.5 and volume<0.3*avg_volume):
                skip this candidate
            
            record result with group tag

注意6/19假期跳过规则：回测代码不仅要跳过选股日，还要确保T+1/T+2日期不会取到6/19的错误重复数据。方案为通过stock_daily实际数据获取trade_date列表，排除已知假期日期。

### 2.4 分组规则

| 组 | 评分范围 | 候选选取 | 说明 |
|:--|:---------|:--------|:----|
| A | total_score < 60 | Top5（评分降序，同分按选取顺序） | 低分组限制数量 |
| B | 60 <= score < 65 | 全部 | 中低分组 |
| C | 65 <= score < 70 | 全部 | 中高分组 |
| D | score >= 70 | 全部 | 高分组 |

### 2.5 数据库依赖

只读：
- `daily_picks` — 选股候选数据
- `stock_daily` — K线数据（open/close/volume/change_pct）

写新表：`backtest_group_results`
- id, batch_id, trade_date, code, name, total_score, group_tag(A/B/C/D)
- entry_price, buy_date, buy_price, sell_date, sell_price, profit_rate, stop_reason, created_at

### 2.6 输出

1. 终端输出每组的：
   - 交易明细表
   - 汇总统计表（次数、胜率、总收益、均值、最大盈利、最大亏损、回撤、连亏）
2. 四组对比矩阵（并排对比）
3. CSV文件：`data/group_backtest_detail.csv`

### 2.7 异常处理

- 数据缺失：跳过并记录日志
- 停牌/一字板：跳过，记录原因
- 假期跳过：6/19
- 区间末尾无T+2数据：跳过并记录

## 3. 验收标准

1. A组每日≤5笔，BCD组无上限
2. 日期覆盖 2026-05-13 ~ 2026-07-21（含边界）
3. 四组结果独立可验证
4. 运行耗时 < 30秒
