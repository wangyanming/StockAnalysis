# 选股策略完整优化方案

## 当前问题

**春秋电子案例复盘：**
- 5/13 涨停选股 ✅（逻辑对，捕捉到资金关注）
- 5/26 买入 ❌（买入时间错位，晚了一周，在涨幅已大时追入）
- 5/14 冲高回落后一买入就陷入回调，连跌后触及-5%止损出局
- 卖在半山腰，随后连续3个涨停

**百通能源案例复盘：**
- 5/26 涨停选股 ✅
- 5/27 买入 ❌（涨停次日直接买，第二天就开始跌）
- 连跌后止损，卖出次日涨停

## 根因分析

**现在流程的问题：** 选股和买入是同一天——涨停当天就入选，次日开盘就买。这导致：
1. 涨停日买入成本最高
2. 涨停次日常有分歧回调，直接买入就是追高
3. 买入后一点回调就触及止损线

## 核心改进：选股和买入分离

新逻辑：

**T日：涨停发生** → 标记为"资金关注"（不入选）
**等待期：跟踪回调** → 等股价自然回调到均线支撑位
**T+n日：确认回调到位** → 当天才选入候选股
**T+n+1日：开盘买入** → 买入点位在均线附近，止损清晰

## 入选条件（新引擎）

### 硬条件
1. **资金印记**：近15天内有涨停（不是今日涨停）
2. **趋势确认**：MA5 > MA10 > MA20（多头排列）
3. **价格位置**：股价在MA20上方（趋势未破）
4. **今日状态**：今日跌幅[-3%, 0%]（缩量回调阴线）
5. **缩量确认**：量比<0.8（抛压衰竭）
6. **回踩到位**：收盘价在MA20上方1%以内或MA5/MA10附近

### 加分项
- 所属板块为当日热点板块
- 流通市值>50亿（非庄股）
- 前一次涨停封板时间早于11:00（强度高）
- 涨停后换手率<10%（惜售）

### 排除项
- ST/*ST/退市
- 科创板688/创业板300/301
- 北交所8/4开头

## 止盈止损
- 入场：次日开盘价买入
- 止损：MA20下方1%（约入场点的-3%~-5%）
- 止盈：遇到涨停不卖（趋势加速持有），涨停打开或连续两日不创新高卖出
