# 止损三问自动化方案

> 创建: 2026-06-01
> 来源: 春秋电子(603890)卖飞复盘 — 触止损时未判断洗盘特征导致卖飞两个涨停

---

## 1. 背景

当前盘中监控(`intraday_monitor.py`)在持仓亏损超-5%时，仅输出"已触及止损线，建议卖出"的文字提醒。主人需要自己打开行情软件查看量能、板块、时间，再做决策。

改进目标：盘中监控自动输出**三问判断结果**，让主人一目了然地知道当前该止损还是该等。

## 2. 需求

持仓亏损触发告警时，盘中监控自动附加以下判断：

| 判断项 | 数据源 | 判断逻辑 |
|--------|--------|---------|
| ① 量能判断 | 当天已成交量 vs 近5日均量 | 量比<0.8→缩量（洗盘信号）; 0.8~1.2→平量; >1.2→放量（真跌信号） |
| ② 板块判断 | 同花顺行业板块实时涨跌幅排行 | 个股所属板块排名前30%→板块强; 后30%→板块弱; 中间→中性 |
| ③ 时间判断 | 系统时间（已有） | <14:00→建议观察; ≥14:00→尾盘窗口，建议执行 |
| 综合结论 | 以上三项加权 | 三项指向洗盘或两项指向洗盘→继续观察; 两项及以上指向真跌→建议止损 |

## 3. 改动范围（小改动，不重构）

**唯一改动的文件：** `core/reporter/intraday_monitor.py`

**不改的文件：**
- `utils/stock_analysis_api.py` — 已有板块查询接口，复用
- `utils/dao.py` — 已有DB查询能力
- `docs/交易纪律.md` — 文档已更新，方案落地后补充说明
- 其他报告文件（`morning_check.py`, `morning_auction_check.py`, `close_report_tpl.py`）— 不涉及

## 4. 新增函数设计

在 `intraday_monitor.py` 中新增以下函数：

### `_get_stock_sector(code: str) -> str`
- 功能：查询个股所属行业板块名称
- 数据源：从 `stock_daily` 表取 `industry` 字段（最近一条有 industry 的记录）
- 返回：板块名称字符串，或 None

### `_get_sector_ranking(sector_name: str) -> dict`
- 功能：获取行业板块在当日所有板块中的涨跌幅排行
- 数据源：`utils.stock_analysis_api.StockDataFetcher.fetch_sector_data()`（同花顺/东财数据）
- 返回：`{'rank': int, 'total': int, 'change_pct': float, 'judgment': '强'|'中'|'弱'}`

### `_get_volume_ratio(code: str) -> dict`
- 功能：计算当日已成交量 vs 近5日均量
- 数据源：
  - 当日量：新浪实时行情 `volume_hand`（单位：手）
  - 5日均量：从 `stock_daily` 表查近5个交易日（不含今日）的 `volume`（单位：股，需 /100 统一为手）
- 返回：`{'ratio': float, 'today_vol': int, 'ma5_vol': int, 'judgment': '缩量'|'平量'|'放量'}`

### `_judge_stock(code: str, name: str, profit_pct: float, current_price: float, prev_close: float) -> str`
- 功能：综合三问输出一段判断文本
- 调用 `_get_volume_ratio` + `_get_sector_ranking` + 系统时间
- 输出格式（见下方）

## 5. 输出格式

当持仓亏损触发时，原本这一行：

```
🚨 中贝通信(603220) 亏损-16.17%，已触及止损线，用三问判断洗盘/真跌（量能/板块/时间），见 docs/交易纪律.md
```

**改为**：

```
🚨 中贝通信(603220) 亏损-16.17%，已触及止损线
  ① 量能：今日量/5日均量 = 0.68 → 🔵 缩量（洗盘特征）
  ② 板块：通信设备 涨幅+1.2%（行业排名 7/90）→ 🟢 板块强
  ③ 时间：10:10 → ⏳ 建议观察，等14:30再决策
  综合判断：🟡 洗盘概率较大，建议观察到尾盘
```

`-5% ~ -3%` 接近止损线的那条：

```
⚠️ 中贝通信(603220) 亏损-4.2%，接近止损线
  ① 量能：今日量/5日均量 = 1.35 → 🔴 放量（警惕）
  ② 板块：通信设备 涨幅-0.8%（行业排名 60/90）→ 🔴 板块弱
  ③ 时间：14:15 → ⏰ 尾盘窗口，关注收盘价
  综合判断：🔴 真跌特征明显，建议准备止损
```

## 6. 数据源说明

| 数据 | 获取方式 | 单位 | 备注 |
|------|---------|------|------|
| 当日成交量（手） | 新浪实时行情 | 手 | `fetch_quote()` 已有，`volume_hand` |
| 5日均量 | `stock_daily` 表 `volume` | 股 | 需 /100 转为手，取最近5个交易日 |
| 所属板块 | `stock_daily` 表 `industry` | 字符串 | 取最新有值的记录 |
| 板块排行 | `StockDataFetcher.fetch_sector_data()` | 涨跌幅% | 同花顺/东财接口 |

## 7. 边界情况处理

| 场景 | 处理方式 |
|------|---------|
| 个股查不到所属板块 | 跳过板块判断，只输出量能+时间两项结论 |
| 今日板块数据未采集（盘前） | 回退到昨日板块排行，标注"昨" |
| 个股当日无成交量（未开盘/停牌） | `volume_ratio` 标记为N/A，不参与综合判断 |
| DB查询失败 | 对应子项标记为❓未知，综合结论变为"数据不足，建议手动判断" |
| 亏损超过-10%（严重超标的） | 直接建议止损，不跑三问（红线规则） |

## 8. 验收标准

1. 持仓亏损-5%以上 → 输出三段三问判断 + 综合结论
2. 量比<0.8 标记缩量，0.8-1.2 平量，>1.2 放量
3. 板块排行前30%标"板块强"，后30%标"板块弱"，中间标"中性"
4. 14:00前标"建议观察"，14:00后标"尾盘窗口"
5. 亏损超-10%→直接止损建议，不走三问
6. 数据获取失败→对应项输出❓，综合结论降级
