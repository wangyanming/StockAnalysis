## 1. 背景与根因

### 1.1 当前问题

v2选股系统（涨停回踩+区间潜伏）的实战验证发现：候选股全是高位末板接飞刀。

以6/12精选5只为证：

| 股票 | 近60日低点→峰值涨幅 | 入选时机 | 问题 |
|:----|:---------------:|:--------|:----|
| 康达新材(002669) | 12.08→19.13 (+58.3%) | 连续2日跌停后入选 | 涨幅大、下跌通道中 |
| 三孚股份(603938) | 23.83→59.98 (+151.7%) | 跌停后入选 | 翻倍股，顶部特征明显 |
| 晋拓股份(603211) | 22.76→33.09 (+45.4%) | 跌停后入选 | 涨停→跌停，接飞刀 |
| 新亚强(603155) | 15.04→25.12 (+67.0%) | 跌停后入选 | 连板涨停后见顶 |
| 昊华科(600378) | 29.93→63.50 (+112.2%) | 跌停后入选 | 接近翻倍，涨跌停交替 |

### 1.2 根因分析

**评分维度全是"追强不追弱"的强度指标**，股票涨得越高→各项指标越漂亮→评分越高→但恰恰是潜在顶部。

v5.5评分体系五个核心维度（筹码25+资金25+板块20+趋势20+大盘10=100）：
- 全部是**正向强度评分**：越强的票分越高
- 缺乏**位置判断**：不知道这只票已经从底部涨了多少
- 缺乏**逻辑判断**：不关心这只票为什么该涨

### 1.3 核心思路转变

从"追强势回调" → **"在启动之前或启动初期就发现股票"**

**方向不变：双轨并行**
- 轨A：**低位启动** — 底部刚冒头，涨幅未过大
- 轨B：**涨停回踩** — 强势股回调到位，但必须排除高位末板

**变化在于逻辑支撑维度的数据来源必须扎实**，每个评分项必须有已有DB数据支撑或有可靠的新增采集方案。

## 2. 双轨框架

### 2.1 整体流程

```
全市场（剔除ST/退市/停牌）
    → 候选池（流动性过滤 + 涨幅过滤 + 市值过滤）
        ├── 轨A检测：满足低位启动条件？
        │     ├── 是 → 轨A评分 → TOP5精选
        │     └── 否 → 跳过
        │
        └── 轨B检测：满足涨停回踩条件？
              ├── 是 → 轨B评分 → TOP5精选
              └── 否 → 跳过
```

两轨独立评分，独立出榜，互不干扰。
两轨都无输出 → 说明当天不适合操作。

### 2.2 轨A：低位启动

**核心逻辑**：找底部刚放量、涨幅还不大、均线刚走好的票。

**触发条件（需同时满足）：**
1. 当日涨幅3-7%（非涨停，涨停即跳过）
2. 量比≥1.5（放量确认）
3. 收盘价>MA5
4. 从近60交易日低点涨幅<50%

**数据来源：** 全部从stock_daily可算出（close, volume, trade_date, change_pct）

### 2.3 轨B：涨停回踩

**核心逻辑**：找近期涨停过的强势股缩量回踩到支撑位。

**触发条件（需同时满足）：**
1. 近5日内有涨停（首板，非连板）
2. 今日缩量回调：量 ≤ 涨停日成交量的90%
3. 回调不破MA10（仍站在10日线上方）
4. 从近60交易日低点涨幅<100%

**数据来源：** stock_daily + daily_limit_up（涨停信息）

### 2.4 两轨的核心区别

| 对比维度 | 轨A 低位启动 | 轨B 涨停回踩 |
|:--------|:-----------|:-----------|
| 选股时机 | 刚启动 | 回踩确认 |
| 涨幅偏好 | 小涨3-7% | 涨停后回调 |
| 位置偏好 | 近60日低点涨幅<50% | 近60日低点涨幅<100% |
| 量能特征 | 放量（量比≥1.5） | 缩量（量≤涨停日成交量90%） |
| 均线特征 | 收盘>MA5 | 回踩不破MA10 |
| 风险等级 | 较低 | 中等（需判断是真回调还是见顶） |

## 3. 评分规则（完整版，每个维度标注数据来源）

总分100分 = 逻辑支撑(20分) + 技术形态(30分) + 位置安全(20分) + 人气辨识度(15分) + 大盘环境(15分)

### 3.1 逻辑支撑（20分）

**核心原则：** 不依赖外部新增数据源，全部用已有DB数据可算。需新增采集的放入"未来扩展"。

#### 3.1.1 板块热度（15分）

| 评分项 | 分值 | 数据来源 | 说明 |
|:------|:---:|:--------|:-----|
| 所属板块当日涨幅排名前5 | +5 | sector_performance | 板块整体走强 |
| 所属板块当日涨停数≥3只 | +5 | sector_performance.rise_count | 板块内涨停多，板块效应强 |
| 所属板块连续3日排名上升 | +5 | sector_performance多日对比 | 板块趋势持续走强 |

**数据来源检查：** sector_performance表有record_date, sector_name, change_pct, rise_count ✅ 全部可直接算

**补充规则：**
- 轨A允许更低标准：板块涨停数≥2只即+3分（低位启动的板块往往还没热起来）
- 轨B用标准规则
- 个股板块归属：从daily_limit_up表中取该股票的industry（如无记录则跳过此项评分）

#### 3.1.2 龙虎榜资金（5分）

| 评分项 | 分值 | 数据来源 | 说明 |
|:------|:---:|:--------|:-----|
| 龙虎榜净买额>0 | +3 | 需新增采集stock_lhb_detail_em | 资金认可 |
| 龙虎榜解读含机构买入 | +2 | 需新增采集stock_lhb_detail_em | 机构参与 |

**数据来源检查：** DB没有龙虎榜数据，需要新增采集 ✅

**当前方案（没有龙虎榜数据时的替代）：**
- 用stock_daily的change_pct和amount判断：当日涨幅>0且成交额大于近5日均量 → +3分（资金活跃）
- 当龙虎榜数据采集上线后，切换为正式规则

### 3.2 技术形态（30分）

#### 3.2.1 轨A：低位启动形态（30分）

| 评分项 | 分值 | 数据来源 | 说明 |
|:------|:---:|:--------|:-----|
| 当日涨幅3-7% | +10 | stock_daily.change_pct | 温和启动，非涨停 |
| 量比≥1.5 | +8 | stock_daily.volume（与5日均量对比） | 放量确认 |
| 连续3日量比>1 | +6 | stock_daily.volume（连续3日） | 持续放量 |
| 收盘价在当日最高1/3以上 | +4 | stock_daily.close与high对比 | 分时强势 |
| MACD零轴附近金叉 | +2 | stock_daily.close计算 | 技术面底部信号 |

**数据来源检查：** 全部可从stock_daily算出 ✅

#### 3.2.2 轨B：涨停回踩形态（30分）

| 评分项 | 分值 | 数据来源 | 说明 |
|:------|:---:|:--------|:-----|
| 近5日内有首板涨停 | +10 | daily_limit_up.board_times=1 | 首板比连板安全 |
| 今日缩量≤涨停日量90% | +8 | stock_daily.volume对比 | 缩量洗盘特征 |
| 回调不破MA10 | +6 | stock_daily.close | 不破关键支撑 |
| 今日振幅>5%且尾盘企稳 | +6 | stock_daily.high-low对比close | 盘中分歧但收稳 |

**数据来源检查：** 全部可从stock_daily + daily_limit_up算出 ✅

### 3.3 位置安全（20分）— 新增核心维度

按近60交易日低点涨幅细分：

| 评分项 | 分值/操作 | 数据来源 | 说明 |
|:------|:--------:|:--------|:-----|
| 从近60日低点涨幅<30% | +10 | stock_daily.close | 低位，最安全 |
| 从近60日低点涨幅30-50% | +5 | stock_daily.close | 尚可 |
| 从近60日低点涨幅50-80% | -5 | stock_daily.close | 偏高，扣分 |
| 从近60日低点涨幅80-120% | -10 | stock_daily.close | 高位预警 |
| 从近60日低点涨幅>120% | 一票否决 | stock_daily.close | 翻倍过的不选 |

**补充说明：**
- 近60交易日低点：取最近60个trade_date的最低价
- 其余条件（距60日高点跌幅等）作为辅助参考，先在报表中显示但不计入评分

### 3.4 人气辨识度（15分）

| 评分项 | 分值 | 数据来源 | 说明 |
|:------|:---:|:--------|:-----|
| 近5日有涨停（轨B必选） | +5 | daily_limit_up | 涨停辨识度 |
| 近5日涨停次数≥2 | +5 | daily_limit_up | 股性活跃 |
| 近10日振幅均值>5% | +3 | stock_daily.high-low | 有波动才有人做 |
| 近5日换手率适中（5-20%） | +2 | stock_daily.turnover_rate | 不要太冷也不要过热 |

**数据来源检查：**
- 涨停次数：daily_limit_up ✅
- 振幅：stock_daily.high/low ✅
- 换手率：stock_daily.turnover_rate ✅

### 3.5 大盘环境（15分）

| 条件 | 分值 | 数据来源 | 说明 |
|:----|:---:|:--------|:-----|
| 大盘涨>0.5% | 15分 | index_quotes | 做多窗口 |
| 大盘±0.5% | 10分 | index_quotes | 正常 |
| 大盘跌0.5-1.5% | 5分 | index_quotes | 谨慎 |
| 大盘跌>1.5% | 空仓（一票否决） | index_quotes | 当天不选股 |

**数据来源检查：** index_quotes ✅

## 4. 候选池构建

统一候选池，两轨共用：

```
全市场 → 仅需要stock_daily和daily_limit_up数据
  ├── 排除：ST股 / 退市股 / 停牌股（close=0或code规则判断）
  ├── 排除：日均成交额<2亿（流动性太差，stock_daily.amount）
  ├── 排除：流通市值<30亿（质量过滤，stock_daily.circulation_market_cap）
  ├── 排除：从近60日低点涨幅>120%（翻倍股不碰，stock_daily.close）
  └── 剩余：约500-800只
```

## 5. 一票否决项

| 条件 | 说明 | 数据来源 |
|:----|:-----|:--------|
| ST/退市/停牌 | — | stock_daily.name含ST或代码规则 |
| 从近60日低点涨幅>120% | 翻倍股 | stock_daily |
| 距60日高点跌幅>30%且无支撑 | 破位下行 | stock_daily |
| 大盘跌>1.5% | 当天不选股 | index_quotes |
| T日涨停 | 不推荐当天涨停票 | stock_daily.change_pct >= 9.4 |
| 近5日有监管函/问询函 | — | **暂无数据，当前不启用** |

## 6. 精选规则

### 6.1 轨A精选TOP5

取轨A评分前5名，硬要求：
- 逻辑支撑≥8分（板块热度条件至少部分满足）
- 位置安全≥5分（近60日低点涨幅<50%）
- 技术形态≥15分
- 无一票否决项

### 6.2 轨B精选TOP5

取轨B评分前5名，硬要求：
- 逻辑支撑≥8分
- 位置安全≥0分（不在极端高位即可）
- 技术形态≥15分
- 无一票否决项

### 6.3 特殊情况

- 轨A无输出：说明今天市场没有底部启动信号，只输出轨B
- 轨B无输出：说明今天没有健康的回调机会，只输出轨A
- 双轨均无输出：空仓日，不推送买入建议
