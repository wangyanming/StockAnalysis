# 方案设计：选股双轨策略 — 低位启动 + 涨停回踩（逻辑驱动）

## 版本记录

| 版本 | 日期 | 修改人 | 说明 |
|------|------|--------|------|
| v1 | 2026-06-15 | 主人+AI | 初始方案：双轨评分体系，逻辑支撑过滤 |

## 1. 背景

### 1.1 当前问题

现有v2选股系统（涨停回踩+区间潜伏）的实战验证发现：

**候选股全是高位末板接飞刀**

| 股票 | 区间涨幅 | 选入时机 | 风险 |
|------|---------|---------|------|
| 康达新材(002669) | 11.55→19.13 (+65.6%) | 6/12连续两日跌停后入选 | 接飞刀概率极大 |
| 三孚股份(603938) | 21.38→64.78 (+202.1%) | 6/12跌停后入选 | 接飞刀概率极大 |
| 晋拓股份(603211) | 20.52→33.78 (+64.6%) | 6/12跌停后入选 | 接飞刀概率极大 |
| 新亚强(603155) | 14.74→25.12 (+70.4%) | 6/12跌停后入选 | 接飞刀概率极大 |
| XD昊华科(600378) | 29.31→63.50 (+116.6%) | 6/12跌停后入选 | 接飞刀概率极大 |

**根因**：评分维度全是"追强不追弱"的强度指标，股票涨得越高→各项指标越漂亮→评分越高→但恰恰是潜在顶部。

### 1.2 核心思路转变

从"追强势回调" → **"在启动之前或启动初期就发现股票"**

关注三个层次：
1. **基本面/题材逻辑是否够硬**（业绩超预期/板块热点/事件驱动）
2. **技术形态是否符合买入条件**（放量上涨、缩量回调）
3. **相对位置是否安全**（排除已翻倍的高位末板）

## 2. 方案概述

### 2.1 双轨策略

```
全市场活跃池（日成交额>2亿 + 非ST/退市/停牌）
    ├── 双轨评分同时计算
    │
    ├── 轨A：低位启动组
    │   目标：在股票刚启动或启动初期发现
    │   特征：底部放量、涨幅<50%、均线刚走好
    │   TOP5出榜
    │
    └── 轨B：涨停回踩组
        目标：强势股回调后二次上车
        特征：涨停后缩量回踩、属于热点板块、回调不破关键支撑
        TOP5出榜
```

### 2.2 评分体系概览

| 维度 | 权重 | 说明 |
|------|:----:|------|
| 逻辑支撑 | 30分 | 基本面硬逻辑 + 题材热点 + 业绩超预期 |
| 技术形态 | 25分 | 放量涨缩量调 + 均线排列 + 量价健康度 |
| 位置安全 | 20分 | 相对低位优先、涨幅过大扣分 |
| 人气辨识度 | 15分 | 板块地位 + 涨停辨识度 + 资金关注度 |
| 大盘环境 | 10分 | 大盘状态（跌>1.5%不选） |

### 2.3 与原v2评分体系对比

| 维度 | v2（现有） | v3（新方案） | 变化 |
|------|-----------|------------|------|
| 筹码结构(25分) | → | **逻辑支撑(30分)** | ⬆ 新增！不再只看技术面 |
| 资金接力(25分) | → | **技术形态(25分)** | ↩ 重构，强调量价关系 |
| 板块环境(20分) | → | **位置安全(20分)** | ⬆ 新增！防止高位接飞刀 |
| 趋势位置(20分) | → | **人气辨识度(15分)** | ↓ 降权，非核心驱动 |
| 大盘安全(10分) | → | **大盘环境(10分)** | ➖ 保留 |
| 位置评估(15分 bonus) | — | 合并到位置安全 | ↻ 融合 |

## 3. 详细评分规则

### 3.1 逻辑支撑（30分）— 新增核心维度

不是简单的技术指标打分，而是判断"这只股票为什么该涨"。

#### 3.1.1 基本面逻辑（15分）

| 条件 | 分值 | 说明 |
|------|:---:|------|
| 近3个月业绩预告/季报超预期 | +10 | DB中已有业绩数据 |
| 所属板块为当日/近3日热点板块TOP3 | +5 | 板块持续有涨停 |
| 个股为热点板块的龙头/核心标的 | +10 | 涨停最早、封板最强、机构覆盖多 |
| 个股有机构调研/研报覆盖 | +3 | 近1月有机构调研记录 |
| 个股属于近期政策受益方向（AI/算力/低空/出海/新质生产力） | +5 | 政策驱动 |

> **上限15分**，防止虚假逻辑堆满。

#### 3.1.2 题材/事件驱动（15分）

| 条件 | 分值 | 说明 |
|------|:---:|------|
| 所属板块当日有≥3只涨停 | +8 | 板块效应 |
| 板块连续3日涨幅榜排名上升 | +5 | 板块持续走强 |
| 个股有消息面事件（龙虎榜/公告/股东增持/回购） | +5 | 事件驱动 |
| 个股有重组/资产注入预期 | +5 | — |

> **上限15分**，与基本面逻辑合并最多30分。

### 3.2 技术形态（25分）— 重构

#### 3.2.1 轨A：低位启动形态（25分）

| 条件 | 分值 | 说明 |
|------|:---:|------|
| 当日涨幅3-7%（非涨停） | +8 | 温和启动，不是一字板 |
| 量比≥1.5 | +5 | 放量确认 |
| 连续3日量比>1 | +5 | 持续放量 |
| MACD零轴附近金叉 | +5 | 技术面底部信号 |
| 收于当日最高1/3以上 | +2 | 分时强势 |

#### 3.2.2 轨B：涨停回踩形态（25分）

| 条件 | 分值 | 说明 |
|------|:---:|------|
| 近3-5日首板涨停（非连板） | +8 | 首板比连板安全 |
| 今日缩量回调（量≤涨停日50%） | +8 | 缩量洗盘特征 |
| 回调不破涨停启动线（或MA10） | +5 | 不破关键支撑 |
| 今日振幅>5%且尾盘企稳 | +4 | 盘中分歧但收稳 |

### 3.3 位置安全（20分）— 新增核心维度

这是防止"高位接飞刀"的关键过滤。

| 条件 | 分值/操作 | 说明 |
|------|:---------:|------|
| 从4月低点至今涨幅<30% | +10 | 低位，安全 |
| 从4月低点至今涨幅30%-50% | +5 | 尚可 |
| 从4月低点至今涨幅50%-80% | -5 | 偏高，扣分 |
| 从4月低点至今涨幅80%-120% | -10 | 高位预警 |
| 从4月低点至今涨幅>120% | 一票否决 | 排除！翻倍过的不选 |
| 距离近60日高点跌幅≤5% | -5 | 刚见顶，不出手 |
| 距离近60日高点跌幅15%-30%，且缩量 | +5 | 回调到位 |
| 距离近60日高点跌幅>30%，且无支撑 | 一票否决 | 破位了，不碰 |
| 近20日处于区间低位分位<40%（轨A） | +5 | 底部启动加分 |
| 近20日处于区间低位分位>60%（轨B） | 只允许涨停回踩 | 高位只做回踩 |

### 3.4 人气辨识度（15分）— 缩编

| 条件 | 分值 | 说明 |
|------|:---:|------|
| 近5日有涨停（轨B必选） | +5 | 涨停辨识度 |
| 近5日涨停次数≥2 | +5 | 股性活跃 |
| 在所属板块内成交额排名前5 | +5 | 板块核心 |
| 近10日振幅均值>5% | +3 | 有波动才有人做 |
| 近5日换手率适中（5%-20%） | +2 | 不要太冷也不要过热 |

### 3.5 大盘环境（10分）— 保留

| 条件 | 分值 | 说明 |
|------|:---:|------|
| 大盘跌>1.5% | 空仓 | 一票否决，当天不选股 |
| 大盘跌0.5%-1.5% | 3分 | 谨慎出手 |
| 大盘±0.5% | 7分 | 正常 |
| 大盘涨>0.5% | 10分 | 做多窗口 |

## 4. 双轨评分流程

### 4.1 候选池构建

统一候选池（不再按价格/市值硬过滤）：

```
全市场（剔除ST/退市/停牌）
    → 日均成交额>2亿（流动性过滤）
    → 市值>30亿（质量过滤）
    → 非近期大涨品种：从4月低点涨幅<120%（排除翻倍股）
    → 候选池：约500-800只
```

### 4.2 双轨评分

**候选池中每只股票同时计算轨A和轨B评分：**

```
轨A评分 = 逻辑支撑 + 技术形态(启动形态) + 位置安全 + 人气辨识度 + 大盘环境
轨B评分 = 逻辑支撑 + 技术形态(回踩形态) + 位置安全 + 人气辨识度 + 大盘环境
```

**轨A触发条件（满足任意=计入轨A候选）：**
1. 当日涨幅3-7%（非涨停）
2. 量比≥1.5且收盘>MA5
3. 从4月低点涨幅<50%

**轨B触发条件（满足任意=计入轨B候选）：**
1. 近3-5日有涨停（首板）
2. 今日缩量回调（量<涨停日50%）
3. 回调不破MA10
4. 从4月低点涨幅<100%

### 4.3 精选（TOP5）

**轨A精选TOP5** — 取轨A评分最高5只，硬要求：
- 逻辑支撑≥15分（必须有逻辑支撑）
- 位置安全≥10分（必须在低位区间）
- 无任何一票否决项

**轨B精选TOP5** — 取轨B评分最高5只，硬要求：
- 逻辑支撑≥15分（必须有逻辑支撑）
- 位置安全≥5分（不在极端高位即可）
- 无任何一票否决项

### 4.4 一票否决项

| 条件 | 说明 |
|:----|:-----|
| ST/退市/停牌 | — |
| 从4月低点涨幅>120% | 翻倍股 |
| 距60日高点跌幅>30%且无支撑 | 破位下行 |
| 大盘跌>1.5% | 当天不选股 |
| 近5日存在监管函/问询函 | 有潜在利空 |
| 近10日累计换手率<5%（流动性枯竭） | 没人玩 |

## 5. DB数据结构

### 5.1 daily_picks 表扩展

现表已支持多轨，添加字段：

```sql
-- 已存在的字段保持不动
-- 新增字段
ALTER TABLE daily_picks ADD COLUMN score_logic INT DEFAULT 0;    -- 逻辑支撑分(30)
ALTER TABLE daily_picks ADD COLUMN score_tech INT DEFAULT 0;     -- 技术形态分(25)
ALTER TABLE daily_picks ADD COLUMN score_pos INT DEFAULT 0;      -- 位置安全分(20)
ALTER TABLE daily_picks ADD COLUMN score_pop INT DEFAULT 0;      -- 人气辨识度(15)
ALTER TABLE daily_picks ADD COLUMN score_mkt INT DEFAULT 0;      -- 大盘环境(10)
ALTER TABLE daily_picks ADD COLUMN track VARCHAR(8) DEFAULT '';  -- 'A'低位启动 / 'B'涨停回踩
```

评分维度名称对照（DB存简写，展示用全名）：
- `score_logic` → 逻辑支撑
- `score_tech` → 技术形态
- `score_pos` → 位置安全
- `score_pop` → 人气辨识度
- `score_mkt` → 大盘环境

### 5.2 复盘视图

```sql
CREATE VIEW v_pick_review AS
SELECT 
    dp.trade_date, dp.code, dp.name, dp.total_score,
    dp.track, dp.score_logic, dp.score_tech, dp.score_pos,
    dp.score_pop, dp.score_mkt,
    sd2.change_pct AS next_day_chg,
    CASE 
        WHEN sd2.change_pct >= 2 THEN '涨'
        WHEN sd2.change_pct <= -2 THEN '跌'
        ELSE '平'
    END AS result
FROM daily_picks dp
LEFT JOIN stock_daily sd2 ON dp.code = sd2.code 
    AND sd2.trade_date = DATE_ADD(STR_TO_DATE(dp.trade_date,'%Y%m%d'), INTERVAL 1 DAY)
    AND sd2.trade_date >= dp.trade_date;
```

## 7. 边界情况

### 7.1 无股票满足轨A条件
- 说明当前市场没有底部启动信号，属于弱势市场
- 轨A组不输出，仅输出轨B
- 在报表中注明"今日无低位启动标的，仅关注涨停回踩"

### 7.2 无股票满足轨B条件
- 说明涨停票全在缩量加速/连板中，没有健康的回踩机会
- 轨B组不输出，仅输出轨A
- 在报表中注明"今日无涨停回踩机会，仅关注低位启动"

### 7.3 双轨均无输出
- 今日不适合交易
- 推荐空仓或仅持有已有仓位
- 在复盘报告中标注强势板块但不推送买入建议

### 7.4 逻辑支撑不明确的标的
- 评分体系中逻辑支撑≥15分为硬门槛
- 如果轨A/轨B TOP5中逻辑支撑均<15分，降级展示但不禁止（标注"无明确逻辑支撑"）
