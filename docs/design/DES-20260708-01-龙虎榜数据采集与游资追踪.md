# 方案设计：龙虎榜数据采集与游资追踪

## 1. 架构设计

### 1.1 模块划分

```
core/fetcher/lhb_fetcher.py     ← 龙虎榜数据采集模块（新增）
utils/data_store.py              ← 添加 DDL 建表 + 数据存储方法（扩展）
core/fetcher/daily_fetch.py      ← 集成到收盘采集流程（修改）
configs/ （后续）                  ← 游资名单可配置（本期写死在代码）
```

### 1.2 数据流

```
每日 16:30 收盘复盘前
    ↓
lhb_fetcher.py → AKShare stock_lhb_detail_em(date) → 爬取龙虎榜明细
    ↓
解析买卖前五席位 → 存入 lhb_detail 表
    ↓
营业部名称匹配章盟主名单 → 写入 lhb_tracker 表
    ↓
（后续可被 close_task.py 引用到复盘报告）
```

## 2. 模块设计

### 2.1 lhb_fetcher.py

```
函数：fetch_lhb_data(trade_date: str) -> dict
  功能：调用 AKShare 获取指定日期的龙虎榜数据
  返回：raw_data(list)，每个元素含股票代码/名称/上榜原因/买卖详情

函数：parse_lhb_detail(raw_data: list, trade_date: str) -> tuple[list, list]
  功能：解析 raw_data，分离出 lhb_detail_rows 和 lhb_tracker_rows
  返回：(lhb_details, lhb_trackers)

函数：save_lhb_data(trade_date: str)
  功能：采集 + 解析 + 存储完整流程
  返回：采集统计信息

函数：run_lhb_today()
  功能：采集今日龙虎榜（自动识别日期）
  返回：采集统计信息

常量：ZHANG_MENG_ZHU_BRANCHES（章盟主营业部名单）
```

### 2.2 data_store.py 扩展

```
函数：save_lhb_detail(conn, rows) -> int
  功能：批量写入 lhb_detail 表（REPLACE INTO）

函数：save_lhb_tracker(conn, rows) -> int
  功能：批量写入 lhb_tracker 表（INSERT）

函数：get_lhb_by_date(conn, trade_date) -> list
  功能：按日期查询龙虎榜数据

函数：get_lhb_tracker(conn, trade_date, trader_name) -> list
  功能：按日期+游资名查询追踪记录
```

DDL 见需求文档第 3 节，通过 `init_db()` 初始化。

## 4. 集成方式

```bash
cd /Users/wangyanming/workspace/StockAnalysis && python3 -c "from core.fetcher.lhb_fetcher import run_lhb_today; run_lhb_today()"
```

### 4.2 收盘流程集成（独立可选）

不在 `daily_fetch.py` 中硬集成（避免破坏现有流程），而是在 `close_task.py` 中调用或在 cron 中独立运行。

## 5. 错误处理

- AKShare 调用失败：重试 3 次，间隔 2 秒
- 网络异常：记录 ERROR 日志，不中断其他采集
- 数据解析异常：跳过单条，记录 WARNING，继续处理其余
- 已有数据不重复写入（REPLACE INTO based on trade_date+stock_code）
- 数据合理性校验：买卖金额为负/数据不全 → 记录 WARNING

## 6. 验收标准

- `python3 -c "from core.fetcher.lhb_fetcher import run_lhb_today; print(run_lhb_today())"` 正常输出采集统计
- 数据库中 `lhb_detail` 表有当天龙虎榜数据
- 数据库中 `lhb_tracker` 表有章盟主相关记录（若有上榜）
- 若章盟主当日无操作，`lhb_tracker` 为空，无异常
- 日期参数支持指定历史日期（非当天）
