# 方案设计：低吸抄底选股引擎 V3

## 背景
原 `daily_pick_v2.py` 使用多维度评分体系（筹码/接力/板块/趋势/大盘/位置），但数据回测显示：
- 连跌缩量见底：42.1%胜率（放弃）
- 涨停次日低开：46.1%（放弃）
- 涨停追高：48%（放弃）

而数据显示大跌抄底+缩量策略胜率65.9%（N=3,478），放量反转胜率60.6%。

## 架构概要
```
daily_pick_v3.py (新增，保留v2)
  ├── pick_stocks_v3()    主流程
  │   ├── 全市场扫描（跌幅≥5%）
  │   ├── MA20乖离率≤-8% 过滤器
  │   ├── 量比<1.5 过滤器
  │   ├── 正分因子加分（阳线/连跌/超跌/低换手/大市值）
  │   ├── 按总分排序TOP5
  │   └── _save_picks_to_db() 落库
  ├── format_v3_picks_for_report() 转close_report_tpl格式
  └── format_v3_report()    独立输出

close_task.py
  └── _build_picks_data() 改为调用 pick_stocks_v3()

close_report_tpl.py
  └── 第5段改为低吸抄底引擎输出格式
```

## 策略规则

### 核心策略A（大跌抄底+缩量）
- 硬条件：跌幅≥5% + MA20乖离率≤-8% + 量比<1.5
- 胜率65.9%

### 备用策略D（放量反转）
- 硬条件：阳线 + 涨幅1-9.5% + 昨日跌≥2% + devMA20≤-6% + 量比>1.5
- 胜率60.6%

### 正分因子（加分，不做硬门槛）
- 阳线 +10
- 连跌2天 +10
- 前5日跌幅≥10%（超跌） +15
- 换手率<5% +10
- 流通市值>30亿 +5

## 数据源
- stock_daily表：MySQL数据库
- 无需外部API

## 影响文件
1. `core/analyzer/daily_pick_v3.py` — 新引擎（新增）
2. `core/analyzer/close_task.py` — 改_build_picks_data调用v3
3. `core/reporter/close_report_tpl.py` — 改第5段模版
