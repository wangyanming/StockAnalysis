# V3选股方案待完善清单

> 本文档记录2026-06-15讨论中发现的问题和待完善点，作为ProductAgent完善方案的依据。

## 一、当前方案中的问题

### 问题1：评分维度数据来源不扎实

现有方案中"逻辑支撑(30分)"的多个子项数据不可用或需要新增数据源：

#### 业绩/季报（原3.1.1a）
- 方案写：近3个月业绩预告/季报超预期 → +10分
- 现实：**DB中无业绩数据**，未采集过
- 建议：暂时去掉，等数据源到位后再加

#### 机构覆盖（原3.1.1c）
- 方案写：近1月有机构调研/研报覆盖 → +3分
- 现实：**AKShare无标准研报覆盖接口**，机构调研未采集
- 建议：**改为"板块内成交额排名前5"**（数据从stock_daily可算）
  - 板块内日均成交额排名TOP5 → 板块核心标的
  - 也可以结合龙虎榜机构席位买入数据（AKShare `stock_lhb_detail_em`）

#### 政策方向（原3.1.1d）
- 方案写：AI/算力/低空/出海/新质生产力 → +5分
- 现实：需要**个股的概念标签数据**，DB中没有
- 建议：
  - 建立静态映射表 `config/policy_sectors.json`（手动维护）
  - 或者新采集概念板块成分股（AKShare `stock_board_concept_cons_em`）

#### 消息面事件（原3.1.2b）
- 方案写：龙虎榜/公告/股东增持/回购 → +5分
- 现实：公告/增持/回购**未采集**，只有龙虎榜数据可用
- 建议：只用龙虎榜（已有 `stock_lhb_detail_em`），其余去掉

#### 重组预期（原3.1.2c）
- 方案写：重组/资产注入预期 → +5分
- 现实：**无结构化数据来源**，这种预期性信息只能靠人工或搜索引擎
- 建议：**去掉这条**

### 问题2：板块条件重复

现状：
- 3.1.1b：所属板块为热点TOP3（+5分）
- 3.1.2a：板块有≥3只涨停（+8分）+ 板块连续3日排名上升（+5分）

重复：板块条件分布在逻辑支撑的两个子项里，实际表达的是同一个东西。

建议：合并为一次评分（板块热度），放在逻辑支撑中。

### 问题3：低位启动时板块可能还没热

现状：3.1.1b "所属板块为当日/近3日热点板块TOP3" — 但低位启动的票，板块往往还没发酵。

建议：板块热度分两级打分：
- **已热**：板块已是涨幅榜/涨停榜TOP3 → +5分
- **正在发酵**：板块涨停数≥2且连续上升 → +3分

### 问题4：大盘跌>1.5%空仓的触发条件

现状：大盘跌>1.5% → 一票否决，当天不选股

现实：有时候是盘中下跌收盘拉回，或者说局部恐慌但个股有独立逻辑。

建议：保持这个规则但加个例外说明——如果个股有特别硬的逻辑（比如业绩超预期+板块不受大盘影响），可以手动覆盖。

### 问题5：涨幅120%一票否决是否过松？

现状：三孚股份(603938)从4月低点涨了151.7%，会被一票否决排除。
昊华科(600378)涨了112.2%，还没到120%线，但6/10~6/11连板期间涨幅从92%→112%，两天就跨过了。

建议：讨论是否需要收紧：
- 保持120%不变（简单粗暴）
- 或者加动态过滤：**近7日涨幅>30%扣分**
- 或者加：涨幅>80%且近3日有涨停 → 扣分（高位连板预警）
