# v7回测改进分析

## 当前问题总结

### 直接原因：大盘联动
亏损的两天（6/4、6/9）的核心问题：
- **6/4选股**：大盘当日-0.64%不算差，但T+1(6/5)大盘继续-0.74%，T+2(6/8)大盘崩-1.70%，跨周末利空放大
- **6/9选股**：大盘当日+1.28%还不错，但大盘隔天就杀跌-0.42%，题材轮动太快

**本质**：v7的大盘评分是静态的快照评分（看选股日当天），没有预测趋势的能力。一天涨一天跌的轮动行情中，大盘评分完全失效。

### 评分问题
- 6/9选股日大盘+1.28%，大盘评分只有7分（规则是>0.5%=10分）
  → 查代码：daily_pick_v3.py 从 index_quotes 查 000001 失败后使用默认sh_change=0 → 大盘评分7分（±0.5%内的默认值）
  → **大盘数据获取有bug**：存的是"szzs"但读的是"000001"

### 根本上：预测性不足
45.7%的胜率意味着v7和大盘随机涨跌的胜率差不多（大约50%）。评分系统没有真正找到"明天哪种形态的票会上涨"的特征。

## 改进方向

### 修复大盘评分bug
daily_pick_v3.py用 index_code='000001' 查，但 index_quotes 表里叫 'szzs'。修复后大盘评分可用。

### 跨周末择时
周五选股 → 周六日消息面未知 → 周一开盘容易跳空低开。
可选：周五减少精选数量(3只)或降低仓位提示。

### 更彻底的改进：从数据出发
不再拍脑袋设计评分维度。直接做统计回测：
1. 遍历stock_daily表中所有历史数据
2. 统计"某形态下T+1上涨的概率"
3. 选概率最高的形态作为选股规则
