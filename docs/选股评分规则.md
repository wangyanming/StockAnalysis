## 一、评分结构（6 维度）

| 维度 | 满分 | 说明 |
|------|------|------|
| 筹码结构 | 25 | 上方套牢盘 / 是否低位启动 |
| 资金接力 | 25 | 换手是否健康 / 是否有接力气质 |
| 板块环境 | 20 | 板块合力 / 是否主线 |
| 趋势位置 | 14 | 均线排列 / 距 MA20 位置（v6.1 去节奏，20→14） |
| 大盘安全 | 10 | 明天还有多少安全空间 |
| 位置评估 | +15 bonus | 20 日区间位置 × 涨跌节奏 联合赋分，独立叠加不稀释 |

- 内部满分合计 = 25+25+20+14+10 + 15(bonus) = **109**
- 对外 `total_score` 封顶 **100**（`max(0, min(100, ...))`）

**维度说明**（核心哲学：判断「明天上涨概率」，不是给「今天表现」打分）：
- 今天涨得多 ≠ 明天继续涨；今天涨停 ≠ 明天能连板；好公司 ≠ 短线好标的
- 重点看：筹码结构、资金接力、板块环境、趋势位置、大盘安全垫

## 二、各维度评分细则（与 `scorer.py` 源码一致）

### 1. 筹码结构（25 分）— `score_chip_structure`

核心：上方有多少套牢盘？现在进去是给前人抬轿还是抄底？
数据源：`stock_daily` 近 20 日 K 线 + 实时行情。K 线 <3 根 → 数据不足，返回 5 分。

| 子项 | 分数 | 逻辑 |
|------|------|------|
| ① 位置 | 10 | 现价在 20 日区间分位 `pos=(price-low20)/(high20-low20)×100`：<30% 低位+10；30~50% 中位+6；50~75% 中高位+3；≥75% 高位追涨 **-5** |
| ② 突破性放量 | 8 | 今日量 / 20 日均量：>2 倍 +8；1.5~2 倍 +4；0.8~1.5 倍正常+0；<0.8 倍缩量 **-3** |
| ③ 筹码沉淀 | 7 | 今日量 < 前期最大量×0.5 → +5（距前期巨量还有空间）；今日量 ≥ 最大量×0.8 → **-3**（接近套牢区） |
| 涨停低位突破 | 2 | 今日涨停(涨幅≥9.5%) → +2 |

最终 `score = max(-10, min(25, score))`。

### 2. 资金接力（25 分）— `score_momentum`

核心：今天进来的资金明天还会继续买吗？有没有接力气质？
数据源：实时行情 + `daily_limit_up` 涨停明细。

**① 换手率判断（12 分）**：
- 涨停票（涨幅≥9.5%），按 `daily_limit_up.turnover_rate`：
  | 换手区间 | 分数 |
  |----------|------|
  | 5% ≤ 换手 ≤ 25% | +12（适中） |
  | 25% < 换手 ≤ 35% | +6（偏大） |
  | 换手 > 35% | -5（过大） |
  | 0 < 换手 < 3% | -8（过低一字板） |
  | 其他 >0 | +6 |
- 非涨停票，按今日量 / 昨日量：1.2~3 倍 +8（温和放量）；>3 倍 +4；<1.2 倍 -3（缩量）

**② 封板质量（8 分，仅涨停）**：
- 封板时间：≤10:00 +5（早盘封板）；≤11:30 +3（午前）；≤14:30 +1（午后）；更晚 -3（尾盘偷板）
- 未炸板(`bomb_times=0`) +3；炸板 >2 次 -3
- 连板数：2 板 +2（晋级）；≥3 板 -5（已太高）

**③ 盘中走势（5 分）**：
- 分位 `pos=(price-low)/(high-low)×100`：涨停且 pos>95% +5（封板在顶部）；非涨停 pos>60% +3（偏强）；非涨停 pos<30% -2（弱势）

最终 `score = max(-10, min(25, score))`。

### 3. 板块环境（20 分）— `score_sector_environment`

核心：板块有没有合力？是不是主线？
数据源：`daily_limit_up` 涨停行业分布。无行业信息 → 返回 5 分。

| 子项 | 分数 | 逻辑 |
|------|------|------|
| ① 板块涨停家数 | 12 | 同行业当日涨停数（剔除跌停）：≥8 家 +12（强合力）；≥5 家 +10（有合力）；≥3 家 +6（有效应）；≥2 家 +3（起步）；<2 家 +0（独苗） |
| ② 最高连板 | 3 | 板块涨停≥3 家时，最高连板 ≥3 板 → +3 |
| ③ 政策题材 | 5 | 名称/行业含关键词（低空经济、AI/算力、半导体、机器人、新能源、消费，每类取首个命中）：命中 +5 |

子项累加后 `score = min(score, 20)`，最终 `score = max(0, min(20, score))`。

### 4. 趋势位置（14 分，v6.1 去节奏）— `score_trend_position`

核心：均线排列？回调到支撑了吗？数据源：`stock_daily` 近 30 日 K 线。K 线 <10 根 → 数据不足，返回 5 分。

**阶段一：大方向硬判别（一票否决制）** — 命中任一条即判下跌趋势，趋势分 ≤5，不进入阶段二：
| 判据 | 条件 |
|------|------|
| MA20 下行 | 现价 < MA20 且 MA20 较 5 日前下行 |
| 短线破位 | 现价 < MA5 且 < MA10 且 MA5 方向向下 |
| 加速下跌 | 近 3 日累计跌幅 > 7% |
| 高位破位 | 从 20 日高点回落 > 8% |
| 连跌不止 | 近 5 日 ≥4 天收阴 |
| 冲高乏力 | 从 20 日高点回落 >6% 且近 5 日无单日反弹 >1% |

命中下跌趋势 → `score = max(-10, min(5, score-5))` 直接返回。

**阶段二：趋势达标后正常评分**（v6.1 仅剩 2 项，满分 14）：
| 子项 | 分数 | 逻辑 |
|------|------|------|
| ② 均线排列 | 8 | MA5>MA10>MA20 多头排列 +8；短多中整理(MA5>MA10 且 MA10<MA20) +4；短期回调中(MA5<MA10 且 MA10>MA20) +2；空头排列 -5 |
| ③ 距 MA20 位置 | 6 | 距 MA20 = (现价-MA20)/MA20×100：-3~0% 回踩 +6；0~5% 上方 +3；>10% 远离 **-3**；<-3% 跌破等企稳 +3 |

> **v6.1 去节奏说明**：原阶段二第④项「近期涨跌节奏」±6 计分段整体删除（满分 20→14），阶段二仅剩 均线排列 8 + 距 MA20 位置 6 = **14 分**。节奏分档逻辑改由位置评估 `_score_position_in_range` 内部现算复用，不再此处重复计分。
> `MAX_SCORES['trend_position'] = 14`，最终 `score = max(-10, min(14, score))`。

### 5. 大盘安全（10 分）— `score_market_safety`

核心：明天大盘继续跌的概率多大？数据源：`index_quotes`（szzs）当日涨跌幅 + `daily_limit_up` 行业分布。

| 大盘状态 | 触发条件（上证 szzs 当日涨跌） | 分数 |
|----------|-------------------------------|------|
| 做多 | 涨 > 1.5% | 10 |
| 正常 | -0.5% ~ +1.5% | 7 |
| 谨慎 | 跌 0.5% ~ 1.5% | 3 |
| 不做 | 跌 > 1.5% | 0 |

**加分**：当日 ≥5 个不同行业有涨停 → +3（板块活跃度高）。
最终 `score = min(score, 10)`。

> 大盘跌 >1.5%（不做）不拦截评分，仅在大盘安全维度体现为低分（0），由其他维度决定总分。

### 6. 位置评估（+15 分 bonus）— `_score_position_in_range`

独立叠加在总分之上，**仅补充不稀释其他 5 维度权重**。满分 15。

**联合赋分：位置 × 涨跌节奏**

- **位置分档**（现价在 20 日区间百分位）：
  | 区间 | 档位 |
  |------|------|
  | <30% | 低位 |
  | 30% ~ 60% | 中位 |
  | 60% ~ 85% | 偏高 |
  | ≥85% | 极高位 |

- **涨跌节奏分档**（近 10 日均涨幅 `avg_chg`）：
  | 条件 | 档位 |
  |------|------|
  | avg_chg > 3% | a 连续大涨 |
  | avg_chg > 1% | b 小幅上涨 |
  | avg_chg > -1% | c 横盘蓄力 |
  | avg_chg > -3% | d 缩量回调 |
  | 其他 | e 持续下跌 |

- **位置 × 节奏 联合赋分表（`_POSITION_RHYTHM_TABLE`）**，满分 15：

| 位置＼节奏 | a 连涨 | b 小涨 | c 横盘 | d 回调 | e 下跌 |
|-----------|:------:|:------:|:------:|:------:|:------:|
| 低位 | 8 | 10 | **15** | 5 | 2 |
| 中位 | 3 | 8 | 3 | 1 | 2 |
| 偏高 | 0 | 5 | 2 | 0 | 0 |
| 极高位 | 0 | 2 | 0 | 0 | 0 |

- **兜底**：近 10 日无 `change_pct`/不足，无法判节奏 → 位置单因子兜底：低位 15 / 中位 8 / 偏高 3 / 极高位 0。
- 区间无效（无数据或扁平区间）或无查表组合 → 返回 0。

> 设计意图：低位横盘(黄金区)拿最高分 15，低位回调/下跌降分，高位不追涨。解决 v6.0「低位无脑+15」与涨跌节奏对回调/下跌惩罚的伪冲突。

## 三、总分加权与评级

**加权公式**（`score_candidate` 实跑逻辑）：

```
weighted =
  max(0, 筹码结构)/25 × w['chip_structure']
  + max(0, 资金接力)/25 × w['momentum']
  + max(0, 板块环境)/20 × w['sector_environment']
  + max(0, 趋势位置)/14 × w['trend_position']
  + max(0, 大盘安全)/10 × w['market_safety']
  + min(1, max(0, 位置评估)/15) × w['position_bonus']

total_score = max(0, min(100, round(weighted, 1)))
```

- 权重 `w` 来自 `config/scorer_weights.json`（当前值：chip 25 / momentum 25 / sector 20 / trend_position 20 / market_safety 10 / position_bonus 15，另含 risk_penalty 15 字段）。
- **归一化口径说明**：趋势维度按 `分数/14 × 权重20` 加权（`MAX_SCORES['trend_position']=14` 作分母），对外 total 仍封顶 100。
- 各维度原始分为负时按 0 参与加权。

**评级 & 仓位建议**：

| total_score | 评级 | 仓位建议 |
|:-----------:|------|----------|
| ≥ 80 | ★★★★★ 强烈推荐 | ≤50% 仓位，竞价看量比确认 |
| ≥ 65 | ★★★★ 推荐 | ≤30% 仓位 |
| ≥ 50 | ★★★ 观察 | ≤15% 仓位，等开盘确认 |
| ≥ 35 | ★★ 谨慎 | 不推荐，仅做自选跟踪 |
| < 35 | ★ 放弃 | 放弃 |

## 四、交易纪律

- 仅做主板票（候选池排除科创板 688 / 创业板 300、301）
- 单票仓位 ≤ 50%
- 止损 -5%
- 大盘跌 > 1.5% 不买（指数 `szzs` 日跌幅判断，在大盘安全维度体现）

## 五、数据源说明

| 数据 | 用途 | 表/来源 |
|------|------|---------|
| `stock_daily` | 20/30 日 K 线（筹码、趋势、位置）；今日行情（收盘后取数）；强势候选(涨幅 2.5~9%) | 数据库 |
| `daily_limit_up` | 涨停明细（换手率、封板时间、炸板次数、连板数、行业） | 数据库 |
| `index_quotes` | 上证 szzs 当日涨跌幅 → 大盘状态 | 数据库（不调外部 API） |
| 新浪实时行情 | 兜底取今日行情（DB 无当日数据时） | 外部 API |
| `config/scorer_weights.json` | 各维度权重 | 配置文件 |
