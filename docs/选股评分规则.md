## 核心哲学 — 预测型评分

**v4 → v5 根本性变更：从"给今天打分"改为"判断明天上涨概率"**

旧版问题：
- 今天涨停 → 形态+8、技术+10、消息催化+15 → **同一个事实算了3次分**
- 今天涨得好 ≠ 明天会继续涨
- 好公司 ≠ 短线好标的

新版逻辑聚焦六个问题：
1. **筹码结构（25分）**：现在进去是给前人抬轿还是抄底？
2. **资金接力（25分）**：今天进来的资金明天会继续买吗？
3. **板块环境（20分）**：板块有没有合力？是不是当前主线？
4. **趋势位置（20分）**：均线走好了吗？在回调到支撑吗？
5. **大盘安全垫（10分）**：明天大盘还有多少安全空间？
6. **位置评估（+15分bonus）**：当前价在20日区间低位还是高位？

## 评分框架

### 1️⃣ 筹码结构（25分）
**核心：上方套牢盘多不多？位置高不高？**

| 子项 | 满分 | 说明 |
|:----|:----:|:-----|
| 位置 | 10 | 近20日低点附近启动→+10，中位→+6，高位追涨→-5 |
| 量价配合 | 8 | 放量>2倍启动→+8，温和放量→+4，缩量→-3 |
| 沉淀情况 | 7 | 距前期巨量还有空间→+5，接近套牢区→-3 |

**数据源：** `stock_daily` 近20日K线（高低点、量能均值）

---

### 2️⃣ 资金接力（25分）
**核心：明天还有人接盘吗？**

| 子项 | 满分 | 说明 |
|:----|:----:|:-----|
| 换手率 | 12 | 5-25%适中→+12，>35%筹码散→-5，<3%一字板→-8 |
| 封板质量 | 8 | 早盘封板→+5，未炸板→+3，尾盘偷板→-3，多次炸板→-3 |
| 分时走势 | 5 | 封板在顶部→+5，弱势→-2 |

**关键约束：**
- 涨停票：看换手率是否适中、封板时间、炸板次数
- 非涨停票：看量比（温和放量→+8，缩量→-3）
- **连板≥3板直接-5分**（太高了不接）

**数据源：** `daily_limit_up` 涨停明细（换手率、封板时间、炸板次数） + 新浪实时分时

---

### 3️⃣ 板块环境（20分）
**核心：个股所在的板块有没有资金认可？**

| 子项 | 满分 | 说明 |
|:----|:----:|:-----|
| 板块涨停数 | 12 | ≥8只→+12，≥5→+10，≥3→+6，2只→+3，1只独苗→0 |
| 板块人气股 | 3 | 板块内最高板≥3板→+3 |
| 政策题材 | 5 | 低空经济/AI/机器人/新能源等关键词命中→+5 |

**数据源：** `daily_limit_up` 当日涨停行业分布

---

### 4️⃣ 趋势位置（20分）
**核心：现在买是顺势还是抄底还是追高？**

| 子项 | 满分 | 说明 |
|:----|:----:|:-----|
| 均线排列 | 8 | 5>10>20多头→+8，空头→-5 |
| 距MA20距离 | 6 | 回踩MA20(-3%~0)→+6，远离+10%以上→-3 |
| 近期节奏 | 6 | 横盘蓄力→+3，缩量回调→+5，连续大涨→-4，持续下跌→-3 |

**数据源：** `stock_daily` 近30日K线（均线、价格、涨跌节奏）

---

### 5️⃣ 大盘安全垫（10分）
**核心：明天大盘继续跌的概率有多大？**

| 大盘状态 | 得分 | 说明 |
|:---------|:---:|:-----|
| 做多（涨>1.5%） | 10 | 做多窗口期 |
| 正常 | 7 | 正常交易环境 |
| 谨慎（跌0.5~1.5%） | 3 | 轻仓为主 |
| 不做（跌>1.5%） | 0 | 总分直接0（开关） |

**加分项：** 当日≥5个行业有涨停→+3（板块活跃度高）

---

### 6️⃣ 位置评估（+15分 bonus）
**核心：现在买是低位捡筹码还是高位追涨？**

| 区间位置 | 得分 | 说明 |
|:---------|:---:|:-----|
| < 30%（低位） | +15 | 近20日低点附近，安全边际高 |
| 30~60%（中位） | +8 | 中等位置，可接受 |
| 60~85%（偏高） | +3 | 位置偏高了，但仍可操作 |
| > 85%（极高位） | 0 | 不扣分，风险扣分/趋势扣分已覆盖 |

**核心逻辑**：这个维度是 **bonus 加分**，不是惩罚。位置高的票已经被趋势扣分（距MA20太远）和风险扣分（连板≥3）惩罚了，位置评分只在低位给加分，高位给0分。

**为什么需要这个维度？**
- 旧版中涨停组高分票全在追涨位（20日区间 >80%），评分高但买入后亏钱
- 低位票（如均胜电子、鲁信创投）评分不突出但

## 总分计算

```
total = 筹码结构(0~25) + 资金接力(0~25) + 板块环境(0~20) + 趋势位置(0~20) + 大盘安全(0~10) + 位置评估(0~15)
total = max(0, min(100, total))   # 上限100
```

位置评分作为 bonus 加在总分后，不稀释其他维度权重，总分截断到 100。

> **2026-07-14调整：** 去掉风险扣分（-15分），原 `get_risk_flags` 依赖AKShare同花顺财务接口，每天评分循环中触发400+次外网请求，导致cron复盘任务间歇性超时。年报财务数据对短线选股价值低，删除后不再影响评分。

## 分组出榜

新版选股结果按照来源**分两组出榜**：

| 组别 | 来源 | 特点 |
|:----|:----|:-----|
| ⚡ **涨停接力** | `daily_limit_up` 涨停热点 | 封板质量、换手率、板块热度综合评分，前5名 |
| 📗 **区间潜伏** | 非涨停渠道（大成交/中阳线/大阳线/活跃平盘） | 趋势位置分≥10；位置评分8~15（剔除高位和极端低位死股）；市值≥50亿。前5名 |

两组各自评分排序后分别取TOP5输出，不再混合排序。

精选入库（`daily_picks`表的`is_pick=1`）：涨停前5 + 低位前5，去重后共10只。与飞书推送一致。

### 趋势位置评分 v5.2 详解

**改动的触发**：2026-05-20 复盘发现选股结果中出现了明显下跌趋势的股票（山子高科-3连阴、粤桂股份-高位回撤16%、京沪高铁-冲高5.25后持续阴跌），原评分系统的趋势分没有大方向判断。

**改动内容**：

```python
# 旧的逻辑（v5.1）
score = 0
if ma5 > ma10 > ma20: score += 8   # 均线多头
if -3 <= dist_ma20 <= 0: score += 6  # 回踩MA20
if avg_chg > -3: score += 5  # 缩量回调
# 结果：山子高科从高点跌了14%、MA5刚拐头，但MA10/MA20还在爬升，判为"上升趋势回调"
```

```python
# 新的逻辑（v5.2）
# 阶段一：硬判别
trend_bad = False
if current < ma20 and ma20_today < ma20_5dago: trend_bad = True
if sum(chg_3d) < -7: trend_bad = True
if (high_20 - current)/high_20 > 8: trend_bad = True
if neg_5d >= 4: trend_bad = True
if drop > 6 and max(pos_5d) < 1: trend_bad = True

if trend_bad: return -5, ['下跌趋势: ...']

# 阶段二：达标后再打分（同v5.1）
score += 均线排列 + MA20距离 + 涨跌节奏
```

**候选池层次过滤**：
| 层 | 条件 | 过滤案例 |
|:---|:-----|:---------|
| SQL层 | code NOT LIKE '688/300/301' + 市值>=100亿 + 成交>5亿 | 密封科技被301过滤 |
| 涨停组 | 趋势分>=0 | 大胜达趋势-5被过滤 |
| 低位组 | 趋势分>=10 | 下跌不充分的票不推荐 |

# 盘中14:30选股评分规则（intraday_pick_1430.py）

> 最后更新: 2026-07-10 18:00
> 实现: `core/analyzer/intraday_pick_1430.py`
> 触发: 工作日14:30（含盘后复盘，command模式直接飞书推送）

## 核心逻辑

不同于收盘选股的6维度精细评分，盘中选股聚焦**当天下午的短期动能**，用更简化的5维度评分体系（满分100分）：

| 维度 | 满分 | 核心逻辑 |
|:----|:---:|:---------|
| 日内强度 | 30 | 涨幅3%~7%区间内，4%~5%最优（抛压适中） |
| 板块热度 | 25 | 个股所属板块在全市场的实时排名 |
| 换手率放量 | 20 | 今日换手率相对于近20日均换手率的放量倍数 |
| 位置评估 | 15 | 60日分位30%~50%最优（低位安全） |
| 大盘环境 | 10 | 上证指数涨跌幅度 |

## 过滤链（顺序不可调）

| 步骤 | 条件 | 过滤量参考（5201→） |
|:---|:-----|:------------------:|
| 全量 | 全市场个股 | 5201 |
| 1 | 不含ST/退市 | ~4800 |
| 1.5 | 仅主板（去掉688/300/4/8开头） | ~3100 |
| 2 | 非涨停（涨幅<9.5%） | ~3000 |
| 3 | 非跌停（跌幅<-9.5%） | ~3000 |
| 4 | 涨幅3%~7% | ~500 |
| 5 | PE>0且PE<200 | ~490 |
| 6 | 60日分位≤70% | ~350 |
| 7 | 大盘安全（上证≤-2%才跳过） | ~350 |
| 通过 | 最终候选 | ~300-400 |

## 评分细则

### 1️⃣ 日内强度（30分）

| 涨幅区间 | 分数 | 说明 |
|:--------:|:---:|:-----|
| 4.0% ~ 5.0% | **30** | 温和上涨，抛压适中，最优区间 |
| 3.0% ~ 4.0% | **25** | 温和启动中 |
| 5.0% ~ 7.0% | **20** | 偏强势，接近涨停区域抛压增大 |
| 其他（3%以下或7%以上已过滤） | 15 | 不计入候选 |

### 2️⃣ 板块热度（25分）

| 板块全市场排名 | 分数 | 说明 |
|:-------------:|:---:|:-----|
| TOP 3 | **25** | 热点板块核心 |
| 4~6名 | **20** | 热门板块 |
| 7~10名 | **15** | 温和热点 |
| 其他 | **10** | 保底分（不作区分） |

> **数据源：** `intraday_sector` 表（同花顺90个行业板块实时排名）
> **注：** 当前盘中个股未匹配板块名，sector_name/sector_rank留空时统一给10分保底

### 3️⃣ 换手率放量评分（20分）

评分基于**放量倍数** = 今日换手率 ÷ 近20日均换手率。

| 放量倍数 | 分数 | 含义（全市场百分位） |
|:-------:|:---:|:------------------:|
| ≥ 2.0x | **20** | P99左右，异常放量，稀有信号 |
| ≥ 1.6x | **18** | P95左右，明显放量 |
| ≥ 1.4x | **15** | P90左右，温和放量 |
| ≥ 0.85x | **10** | 中位数以上，正常水平 |
| < 0.85x | **5** | 缩量，资金清淡 |

> **数据源：** `intraday_stock.turnover_rate`（腾讯接口今日换手率）+ `stock_daily`（近20日历史换手率，`AVG(turnover_rate)`）
> **优点：** 以个股自身历史为基准，不受行业差异影响（银行换手率低、题材股换手率高均可公平比较）

**阈值来源：** 2026-07-10全市场5182只股票的放量倍数统计：
- P50=0.85x, P75=1.07x, P90=1.40x, P95=1.64x, P99=2.33x

### 4️⃣ 位置评估（15分）

| 60日分位 | 分数 | 说明 |
|:-------:|:---:|:-----|
| 30% ~ 50% | **15** | 低位但不失底，最优 |
| 50% ~ 60% | **12** | 中位偏上 |
| 15% ~ 30% | **10** | 偏低，可能左侧 |
| 60% ~ 70% | **8** | 偏高位 |
| < 15% | **5** | 极端低位，可能继续阴跌 |
| > 70% | 0 | 已被过滤链排除 |

### 5️⃣ 大盘环境（10分）

| 上证涨跌幅 | 分数 | 说明 |
|:---------:|:---:|:-----|
| -1.0% ~ +0.5% | **10** | 安全 |
| (-1.5% ~ -1.0%) 或 (+0.5% ~ +1.5%) | **7** | 温和 |
| 其他 | **5** | 谨慎 |

> **大盘开关：** 上证≤-2%时直接跳过选股，不输出候选
> **注：** 仅依赖上证指数，不再看深证/创业板

## 同分排序规则

按 `(score DESC, change_pct DESC)` 排序。同分时涨幅高的排前面，反映更高的当日资金认可度。

## 推送格式

飞书消息包含4部分：
1. **热点板块 TOP5** — 同花顺板块涨幅前5
2. **大盘评估** — 上证涨幅+安全标签
3. **候选股 TOP5** — 代码/名称/现价/涨幅/板块/位置/选入理由
4. **操作提示** — 仓位、止损纪律
